# HTML 页面质量原则

页面设计应服务当前内容，而不是套固定骨架。AI 可以自由选择版式、颜色和交互，但结果必须能被浏览器验证。

## 不变量

- 正文、代码、表格和图表在目标浏览器中完整可读。
- 关闭 JavaScript 或外部资源失败时，核心内容仍然可见。
- 不依赖内网或私有资源；密钥不得进入页面。
- 布局随目标屏幕宽度自然变化，不出现遮挡和非预期横向溢出。
- 动效不阻塞阅读，并尊重 `prefers-reduced-motion`。
- Mermaid 等运行时图表必须实际渲染，不能把源码泄漏给读者。

## 验证

生成后在本地 HTTP 环境打开页面，检查控制台、关键内容、交互和与用户场景相关的屏幕尺寸。验证范围由当前页面决定，不维护统一的逐项清单。截图、控制台结果和页面文件是完成证据。

可按内容需要参考 `Knowledge/规范/html模版/samples/`，但样例不是必须继承的流程或视觉规范。
