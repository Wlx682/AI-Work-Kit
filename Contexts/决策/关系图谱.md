# 关系图谱（Dataview 视图）

> 协议：[[Contexts/决策/关系图谱协议]]
> 此页只读视图。修改 relations 时直接改各文件 frontmatter，跑 `scripts/relations-check.py --write-dependents` 反推。
> 未安装 Dataview 时，下方查询块不会渲染——这是预期行为。

---

## 一、枢纽文件（按依赖热度排序）

> 谁依赖我？依赖越多越是枢纽。

```dataview
TABLE length(relations.dependents) as "依赖我的文件数", relations.dependents as "dependents"
FROM "Contexts" OR "Templates"
WHERE relations.dependents
SORT length(relations.dependents) DESC
LIMIT 20
```

---

## 二、各文件的 depends_on

```dataview
TABLE relations.depends_on as "依赖于"
FROM "Contexts" OR "Templates"
WHERE relations.depends_on
SORT length(relations.depends_on) DESC
LIMIT 30
```

---

## 三、替代链（supersedes / superseded_by）

```dataview
TABLE relations.supersedes as "替代了", relations.superseded_by as "被替代为"
FROM "Contexts" OR "Templates"
WHERE relations.supersedes OR relations.superseded_by
```

---

## 四、未决冲突

> 任何条目都是工作流债务，应尽快收敛。

```dataview
TABLE relations.conflicts as "与之冲突"
FROM "Contexts" OR "Templates"
WHERE relations.conflicts
```

---

## 五、孤立文件（无 depends_on 也无 dependents）

> 候选删除 / 候选合并 / 真正独立。

```dataview
LIST
FROM "Contexts" OR "Templates"
WHERE relations
  AND length(relations.depends_on) = 0
  AND length(relations.dependents) = 0
  AND length(relations.supersedes) = 0
  AND length(relations.superseded_by) = 0
LIMIT 30
```
