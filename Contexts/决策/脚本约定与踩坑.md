# 脚本约定与踩坑记录

> gate / workflow 类 bash + python 脚本的通用约定与已踩过的坑。写这类脚本前先扫一眼。

## bash 踩坑

### 中文全角括号紧贴 `$变量` 会在 `set -u` 下报「未绑定的变量」

**现象**：`workflow-gate.sh` 拼接中文 blocker 消息时写成
`stage_blockers+=("...未满足（$sect_msg）")`，运行时报 `行 N: sect_msg�: 未绑定的变量`（变量名后带乱码字节），且 stdout 被污染成非 JSON。

**根因**：全角括号 `（` 的 UTF-8 尾字节紧贴 `$sect_msg` 时，bash 词法分析把后续字节误并入变量名。`set -euo pipefail` 下直接 abort。

**修法**：变量用 `${var}` 花括号包裹，且**不要用全角括号紧贴变量展开**——拼接中文消息时改用半角 `[ ]` 或在变量与全角符号间留分隔。例：
`stage_blockers+=("${s_label}：交接契约未满足 [${sect_msg}]")`。

**How to apply**：所有 gate/脚本里往数组/字符串塞「中文文案 + `$变量`」的地方，优先半角包裹变量；调试此类诡异「未绑定变量」先怀疑全角标点紧贴展开。

### 内联 `python3 -c` 传中文 JSON 参数易碎

多行 `python3 -c '...'` + 含中文的 `sys.argv` + `set -u` 组合曾触发解析异常。**优先把逻辑放进 `gate_parse.py` 子命令**（用 heredoc `<<'PY'` 或独立脚本），bash 只调一次拿返回值，别在 bash 里内联复杂 python 拆中文数据。`check-sections` 就是这么收敛的——直接透传 JSON 数组串给子命令，不在 bash 里 mapfile 拆数组。
