## 2026-07-04-进化候选-gate_parse-fence判定误配

**类型**：工具缺陷（门禁解析器 fence 配对错位）
**证据**：
- `scripts/gate_parse.py:204` fence 判定为 `line.strip() == "```"`，**不认带语言标注的开栏**（如 ` ```bash `）。
- 后果：子 plan 内若同时存在带语言的代码块（如 CI 命令 ` ```bash `）与纯 ` ``` ` 的 fenced checklist，`in_fence` 状态翻转错位，导致 `[x] N.` 格式的 WBS 勾选**解析为空**，门禁误判「WBS 切片未完成」。
- 实测：自动化测试 plan 用 fenced ` ``` ` 包 `[x] 4.` 解析返回空、门禁卡在 test-first；改用**表格行格式**（首列=4 + ✅）后解析出 `x`、门禁通过。

**改进方向（用户已认领后续治理，暂不落地）**：
1. `gate_parse.py` fence 判定改为 `line.strip().startswith("```")`，正确处理 ` ```bash ` / ` ```json ` 等带语言标注的围栏；或
2. 在模板/规范里统一约定「WBS 切片状态用表格行而非 fenced checklist」，规避配对问题；或
3. `plan-gate-check.sh` 增加预检：子 plan 内 fence 数量为奇数时告警。

**验收方式**：修 `gate_parse.py` 后跑 `python3 scripts/test-workflow-refactor.py`；对含 ` ```bash ` + fenced checklist 的样例 plan 验证 `gate_parse.py wbs-slice-status` 返回正确。

## 2026-07-04-进化候选-看板投影不自动同步

**类型**：门禁问题 / 工具漂移（事实源 ↔ 展示层割裂）
**证据**：
- `scripts/workflow-gate.sh:346` 注释明示「Epic 只是投影，门禁只读子 Plan」；`wbsDone` 判定读的是**子 Plan** 里的 WBS checklist（`wbs_slices_done "$child_file"`）。
- grep 确认 `workflow-gate.sh` / `workflow-status.py` **无任何写 Epic 文件动作**（无 `sed -i` / 文件写入 / 勾选回写）。
