# 炫酷建站规范（Agent 产 HTML · 纳米Work 只托管）

> 用途：凡「把一篇正文做成可分享网页」的 Skill（`weekly-intel-digest`、`best-practice-digest`，未来 `figma-ui` 长文页同理），**由 Agent 直接生成自渲染 HTML 成品**，纳米Work **只负责上传 CDN 并返回短链**，不再负责生成网页。
> 原则见 [[Contexts/决策/Kit核心原则]]。

## 为什么把「造网页」从纳米Work 收回 Agent

| | 旧链路（纳米Work 生成） | 新链路（Agent 生成，本规范） |
|--|------------------------|------------------------------|
| 谁造网页 | 纳米Work 按 `.prompt.md` 现生成 | **Agent 直接产 `.html` 成品** |
| 质量可控性 | 不可控：换行被压平、Mermaid 当文本倒出、样式随机 | **可控**：产完在浏览器实测，过自检才交付 |
| 纳米Work 角色 | 生成 + 托管，一锅端 | **只托管**：上传 CDN + 出短链 |
| 事故先例 | 第3期三张 Mermaid 未渲染、正文段落被压平（见台账） | 自渲染 + 浏览器自检堵住 |

**核心判断**：纳米Work 的生成不可复现、不可验证；Agent 能在本地无头浏览器里跑一遍，图渲染没渲染、报不报错、移动端溢不溢出，肉眼+脚本双确认后再交付。把「造」留在能验证的一侧。

## 交付物（每期三文件，位置见各 Skill）

| 文件 | 内容 | 谁消费 |
|------|------|--------|
| `<slug>.md` | 纯净正文，从标题开始，无机器块 | 读者 / 存档 |
| `<slug>.html` | **Agent 直接产的炫酷自渲染网页成品**，浏览器自检通过 | 交纳米Work 托管 |
| `<slug>.meta.yaml` | AI 卷 skill_run，喂 feedback-aggregate | 脚本 |

> `.prompt.md` **不再是网页生成指令**，降级为「托管指令」并入交接话术（见文末模板）；也可不单独出文件，直接在收尾话术里给纳米Work 一句「把这个 .html 传 CDN、给我短链」。

## 炫酷标准（硬要求 · 第一屏就要不像「白底 Markdown」）

吸收并升级原 `.prompt.md` 对纳米Work 的要求，现在由 Agent 自己实现：

1. **强识别度首屏**：大标题 + 摘要 + 来源/日期/主题标签 + 一个**与本文主题相关的代码生成视觉主画面**（抽象科技视觉/动态网格/悬浮几何，禁廉价图库素材）。首屏视觉元素要能呼应文章核心概念（如本文「大脑/双手/会话」三块 → 首屏三个对应标签方块）。
2. **现代 AI 开发者工具风格**：深色或深浅混合、清晰信息层级、细腻对比；玻璃拟态/霓虹描边/网格背景/终端·代码面板质感择优用，不堆砌到影响阅读。
3. **正文完整渲染**：标题层级、表格、引用、行内/块代码、段落长文阅读舒适。
4. **Mermaid 必须渲染成图形**（见下「技术基线」），放进有设计感的图示容器：标题栏、轻微阴影/描边、深色配色优化；新旧对比图用冷暖色区分。
5. **关键数字必须「主角化」**（重点·参考纳米Work/CodeBuddy 实测差距）：文中的量化结论（如 `p50↓~60%`、`p95↓90%+`）**不能挤在小卡角落**——要用 `clamp(36px,6vw,52px)` 级特大字号、**独占整卡、卡片高大留白足**，滚动进屏时 **count-up 数字滚动动画**入场。数字卡**成组呈现**（3 张一排），且把文章**最核心的一句论点也数字化/公式化**成一张卡（如 `接口 > 实现`），与百分比卡并列，让读者一眼记住三个锚点。
6. **概念对照/要点做成卡片，不埋在正文**：前后对比（旧做法→新做法）、关键论断（如「宠物→牲口」「上下文≠会话」）抽成**小卡片或右侧常驻侧栏**（章节导航 + 读法提示 + 概念对照），长文导航感强；卡片标题加粗、一句话补充，禁大段文字。
7. **克制交互动效**：滚动渐显、章节定位、图示悬停、目录吸顶、返回顶部、数字 count-up；动效轻，不拖慢加载与移动端。
8. **动态适配是硬指标**（重点·用户明确强调「屏幕大小变化要动态适配」）：**不靠单一断点硬切**，主用**流式栅格** `grid-template-columns:repeat(auto-fit,minmax(240px,1fr))`——卡片随视口宽自动 3→2→1 列重排；排版全程 `clamp()`（字号/间距/首屏 padding 都跟视口缩放）；主视觉/侧栏在窄屏优雅降级（侧栏移到正文下方或收起）。**禁**只写一个 `@media(max-width:640px)` 了事。

## 技术基线（避开已知坑 · 强制）

- **Mermaid 自渲染**：页面内嵌 `mermaid.min.js`（CDN，锁大版本如 `mermaid@11`），`startOnLoad:true` + `securityLevel:'loose'` + `theme:'dark'`。**不依赖托管方渲染 Mermaid**——这是第3期事故根因。
- **图源写在 `<pre class="mermaid">` 里**，节点标签中的 `<br/>` 在 HTML 里要转义为 `&lt;br/&gt;`（否则被 HTML 解析器吃掉）。
- **渐进增强，不做「JS 挂了就白屏」**：滚动渐显等动效必须是「默认可见，JS 正常才启用隐藏+渐显」，并加 setTimeout 兜底强制点亮。正文可读性不许赌 JS。
- **变量名避坑**：JS 里禁用 `top`/`name`/`length` 等与 `window` 只读属性同名的全局 `var`（`var top=...` 会静默失败并每次 scroll 抛错）。用 `backBtn` 之类具体名。
- **零私有依赖**：只用公共 CDN（mermaid、字体可选），不引内网资源，保证纳米Work CDN 环境能独立打开。
- **流式栅格（动态适配核心）**：数字卡/概念卡容器用 `display:grid; grid-template-columns:repeat(auto-fit,minmax(240px,1fr)); gap:16px`——无需媒体查询就随视口自动换列。数字字号 `font-size:clamp(34px,6vw,52px)`，首屏 padding、标题都用 `clamp()`，让缩放连续而非跳变。
- **数字 count-up 动画**：数字卡进视口时用 IntersectionObserver 触发一次滚动到目标值（`requestAnimationFrame` 缓动），带 `%`/`↓` 后缀；`prefers-reduced-motion` 时直接显示终值。渐进增强：JS 挂了也要显示静态终值（终值写死在 HTML，JS 只做动画覆盖）。
- **canvas 背景随窗口变化**：粒子/网格背景在 `resize` 事件里重算 `width/height` 与粒子数，避免拉伸模糊；开销大时窄屏可降密度或关闭。
- **自检必测多宽度**：产完至少在 375 / 768 / 1440 三个宽度各验一次无横向溢出（见自检清单）。

## 浏览器自检清单（产完 HTML 必过 · 新增硬门槛）

用本地无头浏览器（Playwright）起静态服务（`python3 -m http.server`，因 `file://` 被拦）实测，脚本 + 肉眼双确认：

- [ ] **三/多张 Mermaid 全部 `hasSVG:true`**（`el.querySelector('svg')` 命中），无一张 `rawTextLeak`（退化成文本）
- [ ] **console 0 error**（favicon 404 属噪音可忽略，其余一律排查到 0）
- [ ] **所有正文 section 最终 `opacity:1` 可见**（滚一遍触发渐显后校验，防「渐显赌 JS」黑屏）
- [ ] **关键数字主角化已生效**：数字卡字号够大（≥34px）、独占卡、成组、count-up 动画能触发（JS 关闭时仍显终值）
- [ ] **全页截图肉眼确认**：首屏不像白底 Markdown、四段/各章都在、图形配色正常、数字够抢眼
- [ ] **多宽度动态适配**：在 **375 / 768 / 1440** 三个宽度各测一次，均无横向溢出、卡片按 auto-fit 正确重排（1/2/3 列）、无文字遮挡
- [ ] 自检产生的截图/临时 server/`.playwright-mcp` 残留**已清理**

> 自检脚本片段（Playwright evaluate）：
> ```js
> // 图是否渲染成 SVG；section 是否全可见；console 报错数
> [...document.querySelectorAll('.mermaid')].map(el=>!!el.querySelector('svg'))
> [...document.querySelectorAll('section')].every(s=>getComputedStyle(s).opacity==='1')
> ```

## 交接纳米Work（新话术 · 只托管）

产物给用户时附一句托管指令（替代原「生成网页」指令）：

```text
交纳米Work（只托管，不生成）：
  1. 把 <slug>.html 上传到 CDN
  2. 返回一个可公开访问的短链接
  （网页已由 Agent 生成并通过浏览器自检，纳米Work 无需改动内容/样式）
```
