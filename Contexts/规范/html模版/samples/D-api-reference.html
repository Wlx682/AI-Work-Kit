GatewayRPC API 参考

与 OpenClaw 网关通信的 RPC 端点集合。所有调用先取 activeRPC 再发起。

集成简介

网关同时承担两种角色：作为 node 接收设备命令，作为 operator 处理聊天与 RPC。凭证按 stableID + userNamespace 隔离存储在 Keychain。

i
本页为「左导航树 + 中参数表 + 右代码常驻栏」的 API 参考版式，正文取自 gateway.md 真实文档。

三层架构

RPCactivateGatewayAndWaitUntilConnected

激活并连接网关的核心入口，等待连接建立完成后返回。

registrationGatewayRegistrationrequired
网关注册信息，含 stableID、host、port、TLS 策略。
!
非本地 host 强制 wss://；TLS 指纹 TOFU 首次信任存 SHA-256。

RPCinjectChat

让网关把一条消息注入会话，经 WebSocket final 事件原路返回渲染。带 createIfMissing: true，超时 10s。

sessionKeyStringrequired
目标会话 key，如 agent:claw_master:main。
messageChatMessagerequired
要注入的消息体。

RPCclawMasterCreateAgent

提交创建智能体。提交前用白名单过滤参数，超时 15s。

允许参数说明
name / icon智能体名称与图标
config / md配置与生成的 Markdown
clawExtensions引擎类型等扩展字段

GETactiveRPC

返回当前活跃网关的 RPC 客户端，无活跃网关时为 nil。

EVTactiveGatewayDidChange

活跃网关切换 / 连接态变化时通过 NotificationCenter 广播，订阅后刷新 UI 与业务态。
