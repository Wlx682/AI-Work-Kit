# 选文筛选与评分标准

> 用途：从每周抓取的候选里，挑出「对技术同学最有帮助」的进周帖。评分透明、可复算。

## 硬性门槛（不满足直接淘汰）

1. **英文一手**：原文是英文，且来自作者本人/官方，非二手搬运、非中文自媒体洗稿。
2. **非视频独立传播**：不接受小红书/抖音/纯视频链接；YouTube 需有可读文字版或值得转写的实质内容。
3. **未发过**：查 [[已发去重清单]]，同一原文/主题近 8 周内未发过。
4. **可被纳米Work翻译**：原文是可提取正文的网页/文档（纯图、需登录墙的除外）。

## 评分维度（各 1–5 分，加权求和）

| 维度 | 权重 | 说明 |
|------|------|------|
| 一手性 | ×3 | 官方作者/论文原作者 = 5；权威转述 = 3；社区总结 = 1 |
| 实操价值 | ×3 | 能直接改进 CC/Codex 用法/工作流 = 5；纯观点 = 2 |
| 时效性 | ×2 | 本周新发 = 5；一月内 = 3；更早但经典 = 2 |
| 覆盖面 | ×1 | 技术+产品/设计/运营都能获益 = 5；纯深水区 = 2 |
| 讨论性 | ×1 | 容易引发跟帖/点赞的话题 = 5 |

**入选线**：加权总分 ≥ 32（满分 50）。每周至少出 1 篇、至多 3 篇候选供你定夺。

## 面向的读者

本区**以技术同学为主**，但产品/设计/运营也参与。因此每篇的中文导语要点出「**技术同学看什么 / 非技术同学看什么**」，让覆盖面维度落地。
