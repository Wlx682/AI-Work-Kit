# Report

Build the report from observable work such as commits, documents, messages, test results and user-provided facts. Distinguish completed outcomes, ongoing work, blockers and unsupported recollection.

Match the audience and requested format. Do not force a standard template or scan unrelated repositories. Missing evidence should be stated, not invented. Write or publish only to the destination the user requested.
