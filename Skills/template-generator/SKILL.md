# Template generator

Infer the real repeated use case and include only fields that future users can reliably fill and use. Distinguish required invariants from optional prompts.

Do not turn a one-off task into a template, and do not introduce stage, status or maintenance fields without evidence that they are needed repeatedly. Reuse an existing format when it already fits. The user chooses where the template is stored.
