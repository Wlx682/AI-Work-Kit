# Kit evolution

Change the smallest stable rule or capability that removes demonstrated repeated friction. Do not preserve a single task's execution details as a permanent workflow, template, field or feedback receipt.

Before editing, identify the evidence, the invariant that should survive future task types and an observable way to verify it. Long-term `Knowledge/` changes require the user's request or confirmation. Skill changes use `Skills/*/SKILL.md` as the sole source and are synchronized with `scripts/sync-skills.py`.

Prefer deletion and consolidation over adding routers, stages or schemas. Validate active control surfaces with `python3 scripts/verify-kit.py`. Report the changed invariant, evidence and any human decision still required.
