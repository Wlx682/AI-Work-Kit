# Material preparation

Identify the recipient and the decision or action the material must support. Extract facts from code, configuration and authoritative sources; separate confirmed values from items the recipient must provide.

Include only information relevant to the handoff. Never copy secrets; use variable names or masked examples. Format and destination follow the user's request. Write to `Knowledge/` only when the user explicitly wants durable reference material.
