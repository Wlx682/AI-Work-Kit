# HTML generation

Choose layout and interaction from the current content and audience rather than a fixed page sequence. Existing samples under `Knowledge/规范/html模版/samples/` are optional references.

Follow `Knowledge/规范/炫酷建站规范.md` for stable browser-quality constraints. Keep core content readable without fragile runtime behavior, avoid private dependencies and never embed secrets.

Open the result through a local HTTP server and verify the page in a browser. The relevant console state, rendered content, responsive layout and user-requested interactions are the completion evidence.
