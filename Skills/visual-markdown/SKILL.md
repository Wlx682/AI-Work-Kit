# Visual Markdown

Use the smallest visual that materially improves understanding: a table for mappings, a flow for sequence, a graph for dependencies, a state diagram for transitions, or a chart for quantitative comparison.

Prefer editable text formats such as Mermaid, PlantUML, Graphviz, D2 or chart specifications. Do not add decorative images or force every document into a diagram. Preserve the source beside the rendered result when practical, and verify that the target renderer can display it.
