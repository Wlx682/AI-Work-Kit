# 模板约定

> **存放原则**（Contexts vs Plans、做完删 plan）→ 只读 [[Contexts/决策/Kit核心原则]]，本文不写第二份。

## 日期

- 占位符 **`{{date}}`**（推荐 `YYYY-MM-DD`）。
- 文件名：`{{date}}-{{title}}.md`。

## Plan 状态（YAML + 正文一致）

```yaml
status: 草稿 | 进行中 | 评审中 | 已采纳 | 搁置
```

## lifecycle_state（Epic 与子 plan）

```yaml
lifecycle_state: requirement | architecture | development | test | deploy | done
```

## Epic frontmatter

| 字段 | 所在 | 说明 |
|------|------|------|
| `epic_id` | Epic | 短 kebab |
| `epic` | 子 plan | `Plans/Epic/xxx.md` |
| `plans.*` | Epic | 各阶段 plan 路径或 `null` |
| `p0_open` | Epic、需求 | 0 才可开发 |
| `含业务逻辑` | Epic、功能 | `是` → 技术方案 `status: 已采纳` |
| `parent` | 子任务 | 主功能 plan |
| `fix_slices` | Bug plan | 重开 WBS 编号 |

门禁：`plan-gate-check.sh` · `full-cycle-gate.sh --epic …`

## Epic 入口

| 场景 | 规则 |
|------|------|
| 新模块 / 含业务逻辑 | 先 `Plans/Epic/` · `/full-cycle` |
| 功能主 plan | 必有 `epic:`；无 Epic → 改走 full-cycle |
| 纯 UI 小改 | `含业务逻辑: 否` + figma-ui + ≤1 人日；仍建议挂 Epic |

例外目录：`Bug排查/` · `代码重构/` · `学习/`。

## 续做（全库唯一）

```text
/resume plan=Plans/【分类】/{{date}}-{{title}}.md 进度=【当前完成情况】
```

## 标签

`tags: [排查, 功能开发, …]` — 标准集见历史 plan 或 Epic 母版。

## 模板清单

| 模板 | 用途 |
|------|------|
| `Epic母版.md` | Epic + WBS 15 |
| `客户端功能开发模板.md` | 功能开发 |
| `技术方案模板.md` | 客户端/服务端方案 |
| `需求分析模板.md` / `需求分析-带验收标准模板.md` | PRD |
| `排查问题模板.md` | Bug |
| `自动化测试模板.md` / `部署模板.md` | 测试/部署 |
| `Figma设计走查模板.md` | 走查 → **Plans/** |
| `资料沉淀模板.md` | PM 物料 → **Contexts/**（通用对照） |
| 日报/周报/学习笔记/概念卡 等 | 见 [[索引]] |

## 路径

| 类型 | 路径 |
|------|------|
| Plan | `Plans/【中文分类】/{{date}}-{{title}}.md` |
| Epic | `Plans/Epic/{{date}}-{{title}}.md` |
| 通用 Contexts | `Contexts/【主题】/` |
