# 查询锦囊（Dataview）

> 高频查询模板。复制代码块到任意笔记，按 Cmd+P → `Dataview: Reload` 即可执行。
> 前置：装 Dataview 插件（Community plugins）。

---

## 一、进行中 plan 全景

> 看现在手上有什么任务、各处于哪个 lifecycle_state。

```dataview
TABLE status, lifecycle_state AS "阶段", file.mtime AS "最后改动"
FROM "Plans"
WHERE status = "进行中" OR status = "草稿" OR status = "评审中"
SORT lifecycle_state ASC, file.mtime DESC
```

---

## 二、P0 未闭环的需求 plan（阻塞清单）

> 哪些需求分析阻塞了下游开发。`p0_open > 0` 不能进 `/architecture-design-assistant`。

```dataview
TABLE status, p0_open AS "P0 未闭", module
FROM "Plans/需求分析"
WHERE p0_open > 0
SORT p0_open DESC, file.mtime DESC
```

---

## 三、90 天未碰的 Contexts（健康检查）

> 候选**冷却 / 删除 / 合并**。月度复盘消费。

```dataview
TABLE file.mtime AS "最后改动", file.size AS "字节"
FROM "Contexts"
WHERE file.mtime < date(today) - dur(90 days)
SORT file.mtime ASC
LIMIT 30
```

---

## 四、关系图谱反查：谁依赖了某个 Contexts

> 改 `Kit核心原则.md` 前先看谁依赖它（避免破环）。改 wikilink 替换为你要查的目标。

```dataview
LIST
FROM "Contexts" OR "Templates" OR "Skills"
WHERE contains(relations.depends_on, "Contexts/决策/Kit核心原则.md")
```

---

## 五、本月 plan 创建节奏

> 看本月新建的 plan 分布，复盘工作流密度。

```dataview
TABLE lifecycle_state AS "阶段", status, file.ctime AS "创建"
FROM "Plans"
WHERE file.ctime >= date(today) - dur(30 days)
SORT file.ctime DESC
```

---

## 用法约定

- 查询块用 ` ```dataview ` 围栏，纯 DQL（不用 JS）
- 修改 `WHERE` / `SORT` 任意调整
- 配合 [[Templates/月度复盘模板]] §六 反馈聚合 + [[Contexts/决策/Skill反馈协议]] 一起读
