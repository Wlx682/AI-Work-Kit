## 一、本节核心（3 句话内）

LLM 按 token 预测下文，受上下文窗口和 temperature 约束。好 prompt 用 CRISPE 说清角色、任务、输出格式和非目标。验证过的 prompt 可固化成 Skill（如 `resume_assistant`）。

---

## 二、关键概念

| 概念 | 我的理解 | 关联笔记 |
|------|----------|----------|
| Token | 模型读写最小单位；Vault 不能全文贴进一次对话 | `[[学习/概念/大语言模型]]` |
| 上下文窗口 | 一次对话能装下的 token 上限；常驻规则放 `.cursorrules` | `[[学习/概念/大语言模型]]` |
| Temperature | 低=稳、重复问答案一致；高=措辞多变、易发散 | `[[学习/概念/大语言模型]]` |
| CRISPE | Context/Role/Instruction/Specification/Examples/Evaluation 六块结构化指令 | `[[学习/概念/提示词工程]]` |
| System vs User | System=常驻规矩（`.cursorrules`）；User=当次任务（`/resume plan=...`） | `[[学习/概念/提示词工程]]` |
| Skill | 固化后的 prompt，触发词反复用 | `[[学习/概念/Skill]]` |

## 三、和 AI-Work-Kit 的联系

- **常驻约束**：`.cursorrules` 只放通用规则，不放当次 plan 全文——对应上下文窗口有限。
- **结构化续做**：`Skills/resume_assistant.md` = 练 A「会议纪要」的同构 Skill——角色（L1–3）、任务（执行步骤 1–7）、输出格式（`## 续做` 模板）。
- **温度选型**：Bug 排查、续做、写 plan 用**低** temperature；想多个 Epic 名或方案可略**高**。
- **我可以马上试的一次**：用 CRISPE 五块写一条「整理站会纪要」prompt（已练 A），再对照 `resume_assistant` 标出 Role/Instruction/Specification（已练 C）。

## 四、好 prompt / 好例子（如有）

**来源**：第 1 课练习 A

```
角色：你是团队会议秘书，擅长从口语化讨论中提取决策与待办。
背景：（贴转写原文）
任务：整理成可执行纪要，突出决策、待办（负责人+截止时间）、风险。
输出格式：## 决策 / ## 待办（表格）/ ## 待确认
不要做什么：不编造、不逐字复述、不给技术实现建议
```
