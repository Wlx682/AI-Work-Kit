# 事件风暴：纳米P视频web首页

**目标**：先用业务事件对齐范围，再进入实例化需求与方案设计。
**说明**：首页无带生命周期的业务聚合根（PRD §6 已确认无状态机）；本墙以「用户交互 / 云控数据加载 / 会员态·积分态转化」三类事件对齐范围与边界。

### 假设决议（选择 A：先按合理假设推进，评审时回收确认）

> ⚠️ 以下为开发侧临时假设，标注 `【假设】`；需求评审时须由产品/后端回收确认，确认后回填并撤销假设标记。

- **H1 决议【假设】**：灵感中心分类 Tab 云控 key 判定为 PRD 笔误。开发按**独立 key** `nano_pvideo_web_hometab` 接入（不与 Banner 复用 `nano_pvideo_web_homebanner`）。真实 key 以产品运营后台配置为准，代码中 key 抽为常量便于替换。
- **H3 决议【假设】**：灵感中心 Tab 内容接口 PRD 未给契约，开发按 PRD 字段描述**拟定一版契约**，方案阶段落地为正式 API Schema：
  - **Tab 列表**（云控）：`{ tabId, tabName, layout: 'waterfall'|'group_scroll', sort }`
  - **瀑布流内容**（分页）：`{ list: [{ workId, cover, coverType:'image'|'video', videoUrl?, title?, ratio, targetType, targetRoute, sameWorkParams }], hasMore, nextCursor }`
  - **分组横滑内容**（整 Tab 一次返回）：`{ groups: [{ groupId, groupName, groupDesc, thumbs:[...], sort, works: [ 同上卡片结构 ] }] }`
  - 卡片 `targetType` 复用四类跳转枚举（功能类/模型类/特效玩法类/特效玩法预览类）。

## 五、输出到实例化需求

- **必须覆盖的主链路事件**：E1 四区块独立加载 / E9 登录 / E10 退出 / E8 会员态分支 / E20 积分明细面板 / E15 Tab 切换双形态 / E18+E19 悬停预览与一键同款 / E26 水印保存。
- **必须写成 Given-When-Then 的边界**：
  - 会员态三分支（订阅 / 非订阅 / 未知兜底）× 胶囊文案 × 面板 CTA 一致性
  - 积分余额接口失败 → `--` 但点击区仍可用（余额与会员态解耦）
  - Banner 首屏/末屏箭头显隐、仅一屏时箭头+指示器全隐
  - 灵感中心 Tab 为空退化单「发现」/ 某 Tab 内容空 Inline 空态 / 某子分组无作品整组隐藏
  - 水印设置：切换仅改本地未保存态、未保存关闭直接丢弃、多端并发以最后保存为准
  - 退出登录：接口失败但本地 token 已失效 → 仍走成功分支
  - 登录态过期不主动弹出、仅在触发需登录操作时拦截
  - 骨架屏：导航栏与 Tab 栏不参与骨架、各区块先到先渲染
- **暂不纳入范围的事件**：站内搜索、个性化推荐算法、国际化/多语言、收银台内部流程（会员/计费 PRD）、资产库页内部、360 用户中心页内部、目标生成页内部拦截。

## 六、实例化需求（Given-When-Then）

> 每条 AC 可被 `test-generator` 映射为自动化用例；标注对应事件与 PRD 锚点。

### 主链路

**S1 · 首页四区块独立渲染（E1/E2）**
- **Given** 用户访问首页根 URL，导航栏与灵感中心 Tab 栏优先渲染（不参与骨架）
- **When** Banner / 工具箱 / 灵感中心内容三区块数据尚未返回
- **Then** 各区块分别展示骨架屏占位（Banner 3 灰块+指示器骨架、工具箱 5 灰块、灵感中心按当前 Tab 形态对应骨架），且**先返回数据的区块先渲染，不互相阻塞**

**S2 · 未登录可完整浏览（E1 未登录态）**
- **Given** 用户未登录
- **When** 首页加载完成
- **Then** 可完整浏览 Banner / 工具箱 / 灵感中心（含悬停预览、悬停按钮）；导航栏右侧仅展示「资产库 + 注册/登录」；首页不主动弹登录引导

**S3 · 登录后仅刷新导航栏右侧（E9）**
- **Given** 未登录用户在首页点击「注册/登录」并完成 360 登录
- **When** 返回首页
- **Then** 导航栏右侧刷新为「资产库 + 积分胶囊 + 升级/充值胶囊 + 头像」；**Banner / 工具箱 / 灵感中心不刷新**

**S4 · 灵感中心 Tab 切换按形态刷新（E15）**
- **Given** 已加载灵感中心，默认选中排序最靠前的 Tab（当前为「发现」）
- **When** 用户点击另一个 Tab
- **Then** 内容区按该 Tab 云控 `layout` 渲染为瀑布流或分组横滑，滚动位置回到内容区顶部；300ms 内连续切换只取最后一次结果、在途请求取消

**S5 · 内容卡片悬停预览 + 一键同款（E18/E19/E25）**
- **Given** 灵感中心某视频类内容卡片
- **When** 鼠标悬停
- **Then** 视频静音自动播放、底部浮现宽度填满的绿色「一键同款」胶囊；点击「一键同款」跳生成页并携带作品参数；点击卡片其他区域跳落地承接页（两区互斥）；鼠标移出即暂停回封面、按钮隐藏

### 会员态分支（三态一致性）

**S6 · 非订阅会员胶囊与面板 CTA 均为「升级」（E8/E20）**
- **Given** 已登录用户为非订阅会员（未开通/已过期/被回收）
- **When** 查看导航栏 / 点击积分胶囊打开面板
- **Then** 升级/充值胶囊文案为「升级」→ 点击进会员订阅收银台；面板底部 CTA 同为「升级」

**S7 · 订阅会员胶囊与面板 CTA 均为「充值」（E8/E20）**
- **Given** 已登录用户为订阅会员（已开通且有效期内）
- **When** 查看导航栏 / 打开面板
- **Then** 胶囊与面板 CTA 均为「充值」→ 点击进积分充值收银台

**S8 · 会员态未知保守兜底为「升级」（E8 异常）**
- **Given** 会员态接口失败**且**无本地缓存
- **When** 展示导航栏胶囊 / 打开面板
- **Then** 二者均保守显示「升级」，按非订阅会员分支处理；会员态缓存后续刷新成功后自动切换为实际文案

**S9 · 订阅成功后胶囊与打开中的面板同步切换（E11）**
- **Given** 非订阅会员通过 CTA「升级」完成订阅并返回首页，且积分明细面板仍处打开态
- **When** 首页重新拉取会员态成功
- **Then** 导航栏胶囊由「升级」→「充值」；**打开中的面板 CTA 同步切换为「充值」**
- **反例**：面板**打开期间**若在另一 tab 完成订阅（本页未重新拉取），面板 CTA **不实时切换**，保持打开瞬间文案，一致性由下次打开保证

### 边界与降级

**S10 · 积分余额失败但点击区仍可用（E7 异常）**
- **Given** 积分余额接口失败
- **When** 已登录用户查看导航栏 / 打开面板
- **Then** 余额位与面板余额摘要均展示 `--`；积分胶囊仍可点击打开面板、升级/充值点击区仍可跳收银台（余额与会员态解耦）

**S11 · Banner 箭头与指示器显隐（E12）**
- **Given** Banner 多屏
- **When** 用户翻屏
- **Then** 首屏隐藏左箭头、末屏隐藏右箭头、非首屏两箭头都在；分页指示器对应「屏」高亮
- **反例**：仅一屏（总数 ≤ 单屏可容纳数）时，左右箭头与指示器**均隐藏**
- **反例**：Banner 数据为空（未配置/失败无缓存）时，**整个 Banner 区块隐藏、下方内容上移**，无空白占位

**S12 · 灵感中心 Tab 与内容空态（E5 异常）**
- **Given** 灵感中心
- **When** Tab 列表为空 / 某 Tab 内容为空 / 分组横滑某子分组无作品
- **Then** 分别为：退化为单个「发现」Tab（不隐藏区块）/ Inline 空态「暂无内容」/ 该子分组整体隐藏
- **反例**：工具箱数据为空时**整块隐藏（含标题与「查看更多」）**，不留占位

**S13 · 区块加载失败/超时可重试（E22）**
- **Given** 某区块请求失败或 >10s 超时
- **When** 首屏加载
- **Then** 该区块 Inline 占位「加载失败，请点击重试」+ 重试按钮，其他区块不受影响；瀑布流/横滑分页失败时**已加载内容保留**，仅失败位展示重试

### Modal / 面板

**S14 · 水印设置本地未保存态（E26）**
- **Given** 已登录用户打开「水印设置」Modal，Modal 打开时拉取服务端初始态
- **When** 用户切换开关但**未点保存**
- **Then** 仅改本地未保存态、状态文字实时更新、**不调接口**；点关闭/遮罩/Esc 直接丢弃改动、不二次确认；下次打开重新拉服务端值
- **AC 补充**：点「保存」→ loading 禁重复 → 成功 Toast「已保存」并关弹窗、仅对新提交任务生效；保存失败 Toast「网络异常，请稍后重试」、弹窗保持打开且保留未保存态
- **反例**：初始态拉取失败时开关兜底「开启」+ Inline「加载失败，请点击重试」，**保存按钮置灰**直到重试成功（避免兜底值覆盖真实值）

**S15 · 退出登录 token 失效仍走成功（E10 异常）**
- **Given** 已登录用户点「退出登录」并确认
- **When** 退出接口失败**但本地 token 已失效**（如已被其他端踢出）
- **Then** 仍走成功分支：清本地态、导航栏刷新为未登录、首页其余区块不刷新、静默纠偏不报错；若积分明细面板打开则强制关闭
- **反例**：退出接口失败**且 token 仍有效**时 → Toast「退出失败，请稍后重试」、Modal 保持打开可重试

**S16 · 登录态过期被动拦截（E27）**
- **Given** 已登录用户登录态已过期
- **When** 用户触发需登录操作（点资产库 / 点积分胶囊）
- **Then** 不主动弹出，仅此时弹 Modal「登录已过期，请重新登录」，按钮「重新登录」「取消」
- **反例**：未登录用户点资产库 → Modal「请先登录后使用」，按钮「立即登录」「取消」

**S17 · 积分明细面板始终打开不拦截（E20/E21）**
- **Given** 已登录用户
- **When** 点击积分胶囊
- **Then** 无论会员态**始终打开**面板（不因会员态拦截或分支）；面板拉首屏 20 条、滚动触底加载下一页、末页「没有更多了」、空态「暂无积分变动记录」；关闭方式支持关闭按钮/遮罩/Esc；点 CTA 跳转前先关面板

## 七、验收标准（AC 勾选）

导航栏
- [ ] 主导航 5 项顺序「首页/视频生成/图片生成/灵感中心/创作工具」，当前页高亮；Logo 点击回首页并回顶
- [ ] 资产库入口登录/未登录均常驻；未登录点击弹「请先登录后使用」
- [ ] 非订阅会员胶囊=「升级」跳订阅收银台；订阅会员=「充值」跳充值收银台；会员态未知兜底=「升级」
- [ ] 积分胶囊点击始终打开面板不拦截；面板 CTA 与胶囊文案会员态一致
- [ ] 订阅成功返回后胶囊与打开中面板 CTA 同步「升级」→「充值」
- [ ] 积分余额失败展示 `--`，点击区仍可用

Banner / 工具箱
- [ ] 横向并列多张、不自动轮播；首屏隐左/末屏隐右/仅一屏全隐；空数据整块隐藏
- [ ] 工具箱空数据整块隐藏（含查看更多）；查看更多跳「创作工具」聚合页

灵感中心
- [ ] Tab 默认选中排序最前项；形态读云控 `layout` 不写死；瀑布流触底分页、分组横滑整 Tab 一次返回
- [ ] Tab 切换回顶 + 防抖 300ms 取最后一次；Tab 空退化单「发现」；内容空 Inline「暂无内容」；子分组无作品整组隐藏
- [ ] 视频卡片悬停静音自动播放 + 浮现一键同款；一键同款/卡片主体互斥跳转

Modal / 状态
- [ ] 水印：切换仅改本地未保存态、未保存关闭丢弃、保存成功 Toast「已保存」、初始态失败置灰保存
- [ ] 退出：接口失败但 token 失效走成功分支；token 有效走失败可重试
- [ ] 骨架屏各区块独立渲染先到先展示；导航栏与 Tab 栏不参与骨架
