# 事件风暴：团队组织架构

**目标**：先用业务事件对齐范围，再进入实例化需求与方案设计。

## 需求一句话

企业账号用户从团队首页点击“全部员工”进入团队组织架构页面，逐级查看部门层级、下钻子部门、查看与搜索部门成员，并按设计稿完成各状态展示。

**需求来源**：
- PRD：<https://geelib.qihoo.net/geelib/knowledge/doc?spaceId=4424&docId=435879#anchor=b53a20df59d54d19a0f4a8652233ea26>
- 接口文档：<https://geelib.qihoo.net/geelib/knowledgeShare?shorturl=a50e3f55fabb102397cb786f4e>
- 响应结构（EasyDoc）：<https://easydoc.qihoo.net/doc?project=cf0c600a6950e7543c14d9e036bdd1d9&doc=8ed0e6d4fcebc26240fabced149f9389&config=title_menu_toc>

**设计来源**：
- Figma 78-10245（顶级部门列表）
- Figma 78-10101（子部门下钻）
- Figma 78-9964（部门成员 + 搜索）

**依赖**：`Plans/Epic/2026-07-16-团队首页.md`——团队首页仅实现了“全部员工”视觉入口，未挂接跳转/请求/状态，本 Epic 承接并**取代**该未完成入口的“点击无动作”非目标。

## 五、异常流程矩阵

| 触发条件 | 用户可见反馈 | 系统行为 | 是否可恢复 |
|----------|--------------|----------|------------|
| 企业上下文校验失败 | 不进入页面；已在页则清空并返回团队首页 | 不发后续企业请求，清除组织/成员状态 | 是，重新登录/切企业 |
| `org_list` 4xx/5xx/超时 | 整页错误态 + 重试 | 不展示旧企业组织数据 | 是，点击重试 |
| `org_member_list` 4xx/5xx/超时 | 成员页错误态 + 重试 | 保留部门标题/面包屑，不显示旧成员 | 是，点击重试 |
| `search_member` 失败 | 搜索结果区错误态 + 重试/清空 | 保留关键字；不误显示上一关键字结果 | 是 |
| 分页失败 | 列表底部重试，不清已加载成员 | 保留当前 pageNum 与已加载项，成功后再追加 | 是 |
| 图片加载失败 | 头像占位 | 不影响姓名与列表滚动 | 是，图片组件可重试 |
| 响应 `success=false` 或数据结构非法 | 对应页面错误态 | 视为请求失败，不使用示例/假数据兜底 | 是，重试/后端修复 |
| 企业切换后旧请求回包 | 无额外提示 | 依据 `enterpriseKey` 丢弃旧响应 | 自动恢复 |
| 快速搜索旧关键字回包 | 无额外提示 | 依据搜索版本/当前关键字丢弃旧响应 | 自动恢复 |

## 七、业务规则（已定，源自团队首页继承）

- R1：仅企业账号可见团队 Tab、可进入组织架构页；非企业账号绝不发起企业接口请求。
- R2：所有组织/成员请求继承团队首页的 `enterpriseKey` 防串数据机制；企业切换后旧响应不得覆盖新企业状态。
- R3：企业请求头沿用 `qid` / `tenant-id` / `idaas-uid`，企业上下文取自 `NMMineModel.brand`（`tenant_id`/`qid`/`idaas_uid`/`company_name`/`company_logo`）。
- R4：跳转在团队 Tab 现有 `UINavigationController` 内 `push`，不新建导航栈。
- R5：设计稿中的示例部门/人名仅为占位，不得作为生产兜底数据。
- R6：组织接口返回递归树（`children` 嵌套），客户端模型需支持递归；字段：`id`/`tenantId`/`idsList`/`code`/`name`/`parentId`/`parentName`/`parentUserId`/`extId`/`children`/`distance`/`leaderFlag`/`position`/`forceDelete`。

## 八、接口清单（客户端代理，前缀 `api/claw/ent/`）

| 用途 | 方法 | 路径 | 入参 | 本期 |
|------|------|------|------|------|
| 组织/部门列表 | GET | `api/claw/ent/org_list` | 客户端不传显式参数，企业身份走请求头/后端注入 | ✅ 用 |
| 部门直属成员 | POST | `api/claw/ent/org_member_list` | query:`pageNum`/`pageSize`；body:`tenantId`/`organizationId`（`tenantId` 由企业上下文提供） | ✅ 用 |
| 成员搜索 | GET | `api/claw/ent/search_member` | query:`pageNum`/`pageSize`+关键字（底层 `keyWord`，全租户模糊匹配手机号/姓名/用户名） | ✅ 用 |
| 部门含子部门成员 | POST | `api/claw/ent/org_members_include_sub` | query:`pageNum`/`pageSize`；body:`tenantId`/`organizationId` | ⛔ 本期不实现 |
| 成员简要/详情 | POST | `api/claw/ent/member_brief` | body:`tenantId`/`userIds:[String]` | ⛔ 本期不实现（属员工-智能体详情页） |

**已确认响应结构（EasyDoc 底层示例，均为 `{data:[...], total, success, ...}` 分页包）**：
- `org_list`（`/out/torg/list`）：递归组织树，节点字段 `id`/`tenantId`/`idsList`/`code`/`name`/`parentId`/`parentName`/`parentUserId`/`extId`/`children`/`distance`/`leaderFlag`/`position`/`forceDelete`。
- `org_member_list`（`/out/torgM/list`）：`data[]` 成员，含 `id`/`username`/`mobile`/`email`/`name`/`displayName`/`picture`/`status`/`memberId`/`userinfoid`，`total` 总数。展示以 `displayName` 为主、`picture` 为头像。
- `search_member`（`/out/tmember/userbykey`）：`data[]` 成员（同上量级字段）+ `total`。

## 九、实例化需求（验收标准，全部可测试；P0 已定稿）

**主链路**
- G1 进入：**Given** 企业账号在团队首页 **When** 点击“全部员工” **Then** 在团队 Tab 现有导航栈内 push 组织架构页，标题“部门”，加载中显示 loading，成功后展示一级部门列表。
- G2 一级部门渲染：**Given** `org_list` 返回单一虚拟根 **When** 页面加载完成 **Then** 展示该根的 `children` 作为一级部门；**And** 返回为顶层数组时直接展示该数组，均按 `name` 逐行渲染。
- G3 下钻二级：**Given** 一级部门列表 **When** 点击一个含 `children` 的部门 **Then** push 子部门列表页，标题为该部门 `name`，展示其直接子部门，可继续逐级下钻。
- G4 进入叶子成员：**Given** 任一层级列表 **When** 点击一个无 `children` 的叶子部门 **Then** push 成员列表页，导航标题为当前部门名，并展示完整部门路径面包屑「父>子」；调用 `org_member_list`（body `organizationId`=该部门 id）分页展示直属成员。
- G5 成员行渲染：**Given** 成员列表已加载 **When** 渲染每行 **Then** 使用 `NMCommonImageView` 展示 `picture` 头像（缺省/失败走占位）+ `displayName` 姓名；无职务字段则不展示职务。
- G6 成员搜索：**Given** 叶子成员列表页搜索框 **When** 用户输入关键字并停顿 300ms **Then** 调用 `search_member`（关键字→底层 `keyWord`）在**全租户**范围模糊匹配手机号/姓名/用户名并展示结果列表；部门层级页不展示搜索框。
- G7 搜索清空还原：**Given** 已展示搜索结果 **When** 清空关键字 **Then** 还原为该叶子部门的直属成员列表。

**边界 / 异常 / 反例**
- G8 非企业隔离（反例）：**Given** 非企业账号 **When** 任意路径 **Then** 不可进入组织架构页，且不发起任何 `api/claw/ent/*` 请求。
- G9 企业切换防串（反例）：**Given** 某企业的组织/成员请求进行中 **When** 用户切换到另一企业 **Then** 旧企业响应因 `enterpriseKey` 不匹配被丢弃，界面只呈现新企业数据。
- G10 返回层级：**Given** 已下钻若干层 **When** 逐次点击返回 **Then** 逐级回到上一级列表；在一级（根）返回则退出组织架构页回到团队首页。
- G11 空部门：**Given** 叶子部门直属成员为空（`data` 空、`total`=0）**When** 加载完成 **Then** 展示成员空态而非空白页。
- G12 搜索无结果：**Given** 搜索关键字 **When** `data` 为空 **Then** 展示“无匹配成员”空结果态，不误显示上一次结果。
- G13 加载失败重试：**Given** `org_list`/`org_member_list`/`search_member` 任一请求失败 **When** 展示错误态 **Then** 提供重试入口，重试成功后正常渲染。
- G14 成员行不接详情（本期反例）：**Given** 成员列表 **When** 点击成员行 **Then** 本期不跳转员工-智能体详情页（该页为独立后续需求，不发 `member_brief`）。
- G15 分页加载：**Given** 成员/搜索列表超过一页 **When** 上滑到底 **Then** 以 `pageNum` 递增加载下一页并追加，无更多时停止请求。
- G16 下拉刷新：**Given** 部门列表或成员列表已加载 **When** 用户下拉刷新 **Then** 以新一代请求重载当前层，旧在途响应因 generation 变化被丢弃，刷新完成后展示最新数据。
