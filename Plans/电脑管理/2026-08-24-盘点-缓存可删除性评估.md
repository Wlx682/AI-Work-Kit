## 一、输入

- 来源：用户询问已盘点缓存中哪些可以删除。
- 范围：按可再生成性、应用运行状态和误伤风险分类，不执行删除。
- 非目标：不删除缓存，不退出应用，不修改用户配置或项目文件。

## 二、阶段产出

- [x] 已完成“优先可清 / 关闭应用后可清 / 建议保留”分类。
- [x] 优先可清项预计约 28.5 GiB，删除后会在下次构建、安装或自动化运行时重新下载。

### 优先可清（低数据风险）

| 缓存 | 约 GiB | 影响 |
|---|---:|---|
| `~/.gradle/caches` | 7.15 | 下次 Android/Gradle 构建重新下载和转换 |
| `~/.npm` | 5.05 | npm/npx 下次重新下载 |
| `~/.cache/uv` | 4.73 | uv 下次重新下载 Python 包 |
| `~/Library/pnpm` | 2.60 | pnpm store 重建，优先用 `pnpm store prune` |
| Playwright MCP + Playwright | 2.04 | 浏览器运行时重新下载 |
| VS Code ShipIt | 1.46 | 更新包重新下载 |
| Trivy | 1.03 | 漏洞数据库重新下载 |
| ToDesktop ShipIt | 0.80 | 对应应用更新包重新下载 |
| pip | 0.74 | Python 包重新下载 |
| CocoaPods | 0.56 | Pods 缓存重新下载 |
| Puppeteer | 0.52 | Chromium 重新下载 |
| Homebrew | 0.51 | formula/bottle 重新下载 |
| vscode-cpptools | 0.50 | C/C++ 工具可能重新索引/下载 |
| pnpm cache | 0.32 | 包缓存重新下载 |
| SwiftPM | 0.24 | Swift 包重新解析/下载 |
| Chroma + node 小缓存 | 0.22 | 模型或工具数据重新生成 |

### 关闭对应应用后可清

| 缓存 | 约 GiB | 条件 |
|---|---:|---|
| `com.openai.codex` + `Codex` | 2.50 | 必须先退出 Codex；会丢缓存但不应删除工作区源码 |
| `~/.cache/codex-runtimes` | 1.55 | 退出 Codex；文档/表格等运行时会重新部署 |
| Google/Chrome | 1.25 | 退出 Chrome；不删除 Application Support 中的书签、密码、Cookies |
| namiclaw | 0.58 | 退出对应应用 |
| LarkShell | 0.43 | 退出飞书/相关应用 |

### 建议交给系统管理

- `icloudmailagent`、`GeoServices`、AppleMediaServices、App Store、CloudTelemetry 等 Apple 系统缓存。
- 原因：体积相对有限，手动删除可能导致重新同步、重新索引或短期异常。
