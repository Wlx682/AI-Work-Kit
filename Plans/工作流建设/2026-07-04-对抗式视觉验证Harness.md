# 对抗式视觉验证 Harness（figma-ui 还原门禁）

## 背景与实验结论

**辩论**：从「技能编排」到「智能体编排」是否需推倒重来（引入事件总线/独立进程/Agent 注册中心）。
**结论**：不推倒。真痛点（自评失效、交接丢失、反馈粗）都可用增量手段解决；「上下文隔离 ≠ 进程隔离」，一次 `Agent()` 子调用即可拿到隔离评判。

**已跑通的实验**（2026-07-04）：
- 靶子：`Skills/figma_ui.md` 第 68-74 行「自评 ≥9 才能报完成」——典型「运动员兼裁判」。
- 做法：全新 context 的对抗验证子 Agent，自己拉 Figma 设计稿（node 34663-7341）+ 自己 Read 实现截图，拿不到主控推理，输出结构化裁决。
- 结果：`pass=false, score=3.5`，6 条偏差。其中：
  - ✅ 真偏差且高价值：**列表最后一行右侧图标语义**（设计稿 `ic-选中 hidden/ic-未选中 visible` = 勾选圈，实现统一做成了移除图标）——藏在 metadata `hidden` 属性里，自评几乎必漏。证明对抗验证能校正自评盲区。
  - ✅ 其它真偏差：底部按钮文案（设计稿「取消」vs 实现「+添加更多专家」）、缺「名称」区块标题、按钮实心 vs 虚线。
  - ⚠️ **误报**：把图层名「知识广场」当成标题真相（实为残留图层命名，语境明显是「创建项目」）。→ 证明对抗裁决**不能单跑即采信，需一道主控复核**。

**两个被实验暴露的工程约束**：
1. 产物必须**落盘成文件**（聊天里的图片喂不进子 Agent）→ 报完成前须真机截图存盘。
2. 验证裁决**须经主控复核**过滤误报 → 流程是 `执行 → 对抗验证 → 主控复核采信 → 写回 Plan`，不是 `执行 → 验证 → 直接 gate`。

## 三段结构（缺一不可）

```
① 产物落盘         ② 对抗验证                ③ 主控复核
figma-ui 真机截图  → 独立子Agent判偏差       → 滤掉误报,标 reviewed=true
存到文件            (全新context,verdict.json)  修正终判 → 写回子Plan
```

门禁只读**第③步产物**（复核后的 verdict.json 文件事实），**gate 不跑 agent**。

## 定案（已拍板）

- **问题1（裁决文件如何被 gate 找到）→ A**：子 Plan frontmatter 加 `verdict: <路径>` 字段，gate 顺着读（与现有 `epicField` 读法一致，显式）。
- **问题2（client-dev 是否条件触发）→ A**：`verdictPass` 用 `onlyIf` 条件触发，仅当该 stage 含 UI 还原切片时生效，不误伤纯逻辑开发。

## 新增 exitCriteria 键：verdictPass

校验（挂进 workflow-gate.sh 现有 crit_has 机制，成为第 9 个键）：
- 从子 Plan frontmatter 读 `verdict:` 路径。
- 文件存在 + JSON 合法 + `pass == true` + `reviewed == true`（防未复核原始裁决直接放行）。
- 不满足 → BLOCKED，输出 deviations 摘要。

## 插入位置

- **client-dev**：`development` 阶段 exitCriteria 加 `verdictPass`，配 `onlyIf`（含 figma-ui 标注的 UI 切片才触发）。
- **ui-change**：`ui-implement` 阶段 exitCriteria 加 `verdictPass`（无条件，纯 UI 流程本就是还原任务），作为进入 ui-review 的前置闸。

## verdictPass 行为矩阵（已实测）

| 模式 | verdict 字段 | 裁决 | gate |
|------|:---:|:---:|------|
| `ifPresent`(client-dev) | 无 | — | 豁免→done |
| `ifPresent` | 有 | pass=false | BLOCK+列P0 |
| `ifPresent` | 有 | pass&reviewed=true | done |
| `required`(ui-change) | 无 | — | BLOCK 缺字段 |
| `required` | 有 | pass&reviewed=true | done |

## 设计边界（守核心原则）

| 边界 | 决定 |
|------|------|
| 门禁跑不跑 agent | 不跑，只读 verdict.json 文件事实（守「文件即状态」） |
| 谁跑验证子 agent | figma-ui Skill 收尾时跑，不是 gate 跑 |
| 原始裁决能否直接放行 | 不能，须 reviewed=true |
| 纯逻辑开发要不要验证 | 不要，onlyIf 有 UI 切片才触发 |
