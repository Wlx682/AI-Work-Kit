# 子任务 T03：企业 API 与映射

## 输入

- T02 模型/参数。
- `api/claw/ent/org_list`、`org_member_list`、`search_member` 契约。
- 既有 `NMTeamEnterpriseRequest`、`NMClawHubRequestHandler` 的 GET/POST 与错误处理模式。

## 输出

- 在 `NMClawAPI` 新增 `Ent.org_list`、`Ent.org_member_list`、`Ent.search_member`。
- 新增 `NAMIWork/Features/Team/Org/NMTeamOrgRequestHandler.swift` 并注册到 App target。
- 三个可注入完成回调的加载方法，返回 `NMSimpleRequest?`、组织树或 `NMTeamOrgPage<NMTeamMember>`。
- 网络/业务失败、`success=false`、结构非法和空数据的明确映射。

## 验收

- `org_list` 为 GET 且客户端不传 query/body；企业身份仅走既有请求头。
- `org_member_list` 为 POST：分页在 query，`tenantId/organizationId` 在 body。
- `search_member` 为 GET：`pageNum/pageSize/keyWord` 在 query，范围不附带部门 ID。
- 不新增或调用 `org_members_include_sub`、`member_brief`。
- 错误不使用 Figma 示例/假数据兜底；空数组+total=0 作为成功空态交给 ViewModel。
- 相关参数与映射测试转绿；新增文件注册正确，`project.pbxproj` 合法。
