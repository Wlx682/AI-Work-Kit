# 子任务 05：项目输入框改造 + @ 交互

**WBS**：#7/#8 | **依赖**：子任务02 | **Figma**：3.4 / 3.5

## 目标

改造项目输入框（默认专家+文案），接入 @ 专家浮层与 @标记协议。

1. **输入框改造（`NMProjectDetailInputBarView`）**：
   - placeholder 改「输入问题」（D4）
   - 默认专家（PRD 3.5）：项目有专家→agentChip 显示**项目专家列表第 1 个**；无专家→显示**纳米AI助理**（`namiWorkAgentId()`，`+HomepageAgent.swift`）
   - 点 agentChip → 打开专家选择弹窗（复用子任务03 Picker）；专家列表底部「添加更多」入口；触发对话后所选专家安装并加入项目列表，纳米AI助理不再显示
2. **@ 交互（PRD 3.4，复用 `NMMentionExpertPopupController`）**：
   - 输入框输入 `@` → `NMMentionExpertPopupController.show(agentsProvider: { 当前项目专家列表 })`（注入项目专家，**零改浮层**）
   - 选中 → 输入框插入 `@[显示名](agentId)`（markdown link 协议）→ 渲染为**蓝色可点击 tag**，可删（删对应文本标记）
   - 多 @：同一消息可插多个标记
   - **空态**：项目无专家 → 浮层「暂无专家，请先添加」+ 跳专家团 Tab 按钮
3. **发送**：复用 `chat.send`（project 域 sessionKey，message 含 @标记，**string 不加字段**）/ `projectSessionCreate`。后端正则提取 @ 分派；被 @ 未安装专家由后端自动沉淀进项目专家列表（客户端无需额外调用）。
