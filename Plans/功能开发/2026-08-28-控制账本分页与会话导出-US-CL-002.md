# US-CL-002：导出当前会话的固定边界 JSON 快照

作为控制账本使用者，我想从详情页导出当前 Session 的完整固定边界 JSON，以便审计、排查和离线留档。

## 验收标准

- AC6：首次 query 固定 latestSequence，按页汇集大会话；空会话导出合法空 events。
- AC7：任一后续页失败不生成下载；导出中重复点击不启动第二条链路。
- AC8：文件名安全，schema v1 JSON 含 exportedAt、runId、capturedThroughSequence、summary、dossier、完整有序 events。
- AC9：未传 throughSequence 的旧 `queryRun` 与“加载更多”行为保持兼容。
- AC10：全量测试、typecheck、build 通过并更新 `lib/` 与 README。

## 故事内部实现边界

- UI / 交互：详情标题区导出、忙碌禁用、失败恢复与中英文文案。
- Domain / 状态：首次 snapshot 作为 summary/dossier 真值；throughSequence 固定后续页；全部成功才下载。
- Data / API：扩展可选 `throughSequence`，复用 `queryRun` 有界分页，不新增无界 export Remote。
- 测试与异常：250 条多页、运行中追加、空会话、第二页失败、重复点击、文件名与 JSON schema。

## 架构引用

- ADR-003：客户端复用 `queryRun` 分页汇集。
- ADR-004：固定 `throughSequence`。
- ADR-005：schema v1 JSON。

## 实现落点设计

- 代码证据：`src/projection.ts`、`src/types.ts`、`src/typert.ts`、`src/client/index.ts`、`src/client/ControlLedgerPage.tsx`、现有 projection/service tests。
- 目标文件：扩展可选事件上界并修改详情入口/locale/CSS/README；新增 `src/client/export.ts` 与 `tests/client-export.spec.ts`。
- 模块边界：Host 仍只返回有界页；纯 collector 固定首次边界；全部成功后 adapter 才执行 Blob 下载；React 只维护 single-flight UI 状态。
- Red 测试位置：`tests/projection.spec.ts`、`tests/service.spec.ts`、`tests/client-export.spec.ts`；命令见 `implementation_design` JSON。
