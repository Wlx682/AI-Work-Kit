# 子任务 T02：模型与参数

## 输入

- T01 测试骨架。
- 组织树、成员与分页包接口字段。
- 技术方案中的递归节点、单虚拟根展开、叶子判定、显示名回退和纯参数接缝。

## 输出

- 新增 `NAMIWork/Features/Team/Org/NMTeamOrgModels.swift` 并注册到 App target。
- `NMTeamOrgNode`、`NMTeamMember`、`NMTeamOrgPage<T>`。
- `NMTeamOrgTree.firstLevel(from:)`、部门路径/面包屑纯逻辑、稳定成员 ID。
- `NMTeamOrgRequestParams`：成员 query/body、搜索 query、企业 headers。

## 验收

- `children` 递归映射且空/缺失时 `isLeaf=true`；单虚拟根只展开其 children，多顶层原样返回。
- `displayName` 按 `displayName → name → username` 回退，头像可空。
- 成员请求 query 仅含 `pageNum/pageSize`，body 含 `tenantId/organizationId`；搜索使用 `keyWord`，空白关键字不生成搜索参数。
- 企业 headers 与既有 Team 请求的 `qid/tenant-id/idaas-uid` 一致。
- T01 对应模型和参数测试转绿，其他未实现测试保持红；`project.pbxproj` 合法。
