# 子任务 04：@ 项目专家输入（3.6 / D1）

**WBS**：#7 | **依赖**：03

## 目标

项目任务提示词支持 @ 引用当前项目专家（纯文本标记，不改执行者）。按需求 P0-3：点「具体要求」→ 独立文本输入页，右下角有 @ 按钮（Figma），点 @ 或输入 @ 都触发插入项目专家；参考现有插入专家开发（交互一致、页面与数据源不同）。

1. **提示词输入承载 @ 能力**：复用 `NMInputBar` 的 mention 机制（`textInputComponent.isMentionExpertEnabled` + `mentionExpertProvider` + 工具栏 `onAtButtonTapped` → `openMentionExpertPicker()`，参考 `NMChatViewController.enableMentionExpert` 第1557行）。
   - 若现有定时任务创建页的"具体要求"是只读 label + 跳转输入页：在该输入页接入上述 @ 能力（右下角 @ 按钮）。
2. **数据源换项目专家**：`mentionExpertProvider` 返回**当前项目绑定专家**（接 `projectExpertsList(projectId)`，二期占位见 `NMChatViewController:1547` TODO；若接口未就绪，先用二期同款占位并标 TODO）。
3. **降级（AC4-反 / B1）**：项目无绑定专家 → @ 不触发浮层，作为普通字符输入；@ 按钮可隐藏或点击无候选态。
4. **插入结果**：光标处插入「@专家名」纯文本，随提示词一起进 `model.prompt`，不额外加执行者字段。

## 验收
