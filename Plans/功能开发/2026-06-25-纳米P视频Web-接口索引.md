# 接口索引：纳米P视频 Web（pvideo）

> **真理源（飞书）**：https://my.feishu.cn/docx/SFTodXNwWoFPFwxN7ifcNeKgnqh  
> **Path 列状态**：`待核对` = 技术方案推断，WBS#5 联调前必须与飞书逐条对齐。

## 通用

| 项 | 说明 |
|----|------|
| Base URL | `https://{HOST}/api/pvideo/...` |
| 鉴权 | Cookie/Header `Q` + `T` |
| 响应 | `{ code, msg, timestamp, data }` |

| 能力 | Method | Path | 说明 | 状态 |
