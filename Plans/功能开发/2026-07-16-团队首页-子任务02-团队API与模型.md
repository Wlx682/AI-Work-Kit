# 子任务 T02：团队 API 与模型

## 输入
- `api/claw/list`：`available_scopes=ee`，禁止 `category_id`。
- `GET /api/claw/total`：`data.skill_total`。

## 输出
- `NMTeamAgentListQuery`、`NMTeamTotalsParser`、`NMTeamAgentAccumulator`。
- `NMTeamRequestHandler`、企业请求 Header、分页 page model。

## 验收
- 初次/分页请求均固定 `ee`，仅分页追加非空 `npt`。
- Skill 只读取 `skill_total`；`claw_total` 不参与智能体数量。

## 依赖
- 无。

## 覆盖 AC
AC3, AC4, AC4-反, AC5, AC10

## 实施结果
- `api/claw/list` Team 专用参数固定为 `appsource=bot&available_scopes=ee`，不写入 `category_id`。
- `/api/claw/total` 追加企业 Header，并且解析器只读取 `data.skill_total`。
- 已实现跨页 ID/clawName 去重累计器；XCTest 已覆盖参数、解析与去重契约，执行受主工程既有错误阻塞。
