# 子任务 01：数据模型与云控

**WBS**：#4 | **依赖**：无（最先做）

## 目标

落地二期所有数据结构与云控读取，为 Service/UI 提供类型基础。不含网络调用（RPC 在子任务02）。

1. **NMProjectExpertRow**（新建，`GatewaySessionModels.swift` 或 Projects/Model）：对齐契约 `ExpertRow`——`agentId/name/avatar/description/source`（均 string；name 缺省 fallback agentId，avatar 空串=无头像）。Codable/Mappable。
2. **NMProjectRecord 扩展**（`GatewaySessionModels.swift:138`）：加 `expertCount: Int`（有效专家数，过滤已下架）；同步 `replacingFileCount` 等便捷构造。
3. **SessionHistoryItem 扩展**（项目内会话行模型）：加可选 `taskType: String?`("swarm")、`swarmTaskId: String?`、`memberAvatars: [String]?`、`memberCount: Int?`。
4. **RecommendProjectItem**（新建 Mappable）：`icon: [String]`(索引/URL)、`showName`、`realName`、`sort: Int`。
5. **云控方法**：`NMCloudConfigManager+AppBaseSet` 加 `projectRecommendationInfo() -> [RecommendProjectItem]`，照搬 `homepage_bottom_input_box_expert_110` 范式（`+HomepageAgent.swift:107`）：`assistantClawAppBaseSet()` → key `project_recommendation_info` → `mapJson` → `Mapper`，按 sort 升序。缺失/解析失败返回空数组（静默降级）。

## 验收

- [ ] 各模型字段与契约一致，可正确解析后端 JSON（含缺字段容错）
- [ ] `projectRecommendationInfo()` 解析云控 JSON 字符串成功，按 sort 升序；key 缺失返回空数组不崩
- [ ] 编译通过（`xcodebuild build ... generic/platform=iOS`）
