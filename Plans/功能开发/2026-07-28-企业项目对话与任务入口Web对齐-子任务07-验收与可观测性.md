# 子任务 07：验收与可观测性

## 一、需求分析与目标范围

汇总 T01–T06 的自动化、静态、日志和真机证据，验证 AC-01～AC-17，并确保测试门禁豁免没有被误报为测试通过。

- 需求分析：`Plans/需求分析/2026-07-28-企业项目对话与任务入口Web对齐.md`
- 技术方案：`Plans/技术方案/2026-07-28-企业项目对话与任务入口Web对齐.md`

## 二、输入

- T01–T06 的实现和子任务验收记录。
- 自动化测试 Plan、现有 `NAMIWorkTests/ClawTests.swift` 与真机 xcresult。
- 需求 17 项 AC 和技术方案日志/隐私约束。

## 三、输出

- 补充 `NAMIWorkTests/ClawTests.swift` 的 Merger、Loader、Socket、Binder、Coordinator 测试。
- 项目/Gateway/session 的脱敏可观测日志与错误分类。
- AC-01～AC-17 证据矩阵、静态范围检查与 iPhone/iPad 真机验收清单。
- 测试工程恢复前后的执行结果分栏记录。

## 四、实现边界

- 不在本任务顺手修复无关的 `Claw` 模块或 `PRTextStorage.h` 测试基础设施，除非另行授权。
- 不修改 MainList/Search 以增加项目任务过滤或路由。
- 日志不得输出 token、Cookie、完整消息正文或其他敏感字段。
- 未实际启动的 XCTest 只能标记 blocked，不能标记 pass。

## 五、验收标准

- [ ] AC-01～AC-17 均有实现、自动化/静态或真机证据。
- [ ] Gateway 真相源、HTTP 软失败、入口前 Socket、绑定顺序和端一致性均有失败路径覆盖。
- [ ] MainList/Search 无范围外改动。
- [ ] 日志能定位 project/gateway/session 阶段且敏感信息脱敏。
- [ ] XCTest 已按用户指示退出本轮范围，保留原始阻塞证据且不得记为通过。

## 六、依赖与阻塞

- 依赖 T01–T06。
- 测试目标仍存在缺失 `Claw`、Bridging Header 缺 `PRTextStorage.h` 的既有问题；用户已批准 WBS 4 例外并明确本轮不再处理 XCTest，因此它不再阻塞 App 构建/安装，但仍需如实保留。

## 七、验证

- `swiftc -parse`、`git diff --check`、目标文件范围与敏感日志静态检查。
- XCTest 不纳入本轮执行，保留 blocked 证据而非绿色结论。
- iPhone/iPad 自有/共享项目、既有/新建任务、断网/无权限/快速切换验收。

## 八、当前进度

- Merger、Loader、Binder、Coordinator 及 iPhone/iPad 接入测试代码已写入 `ClawTests.swift`。
- 所有本次修改 Swift 文件通过语法检查；Coordinator 通过 Swift 6 strict-concurrency 独立类型检查；pbxproj、`git diff --check` 通过。
- 静态范围检查确认 `Features/Conversation/MainList/` 与 `NMTaskSearchViewController` 无改动。
- 新增日志只记录 project/session/gateway 标识和错误，不包含 token、Cookie、身份 Header 或消息正文。
- `NAMIWork` Debug App 已面向 `longxiang的iPhone` 真机构建成功；期间修复 `NMProjectChatEntryCoordinator` 默认参数触发的 Swift 6 MainActor 编译错误。
- 产物 bundle id 为 `com.qihoo.namiwork.dev`，已安装并启动；设备进程列表确认 App 进程正在运行。
- XCTest 按用户指示退出本轮范围，原 blocked 事实保留且不记为 pass。
- 命令行无法代替登录态下的触屏操作；iPhone 企业项目既有/新建任务、断线/无权限/快速切换，以及 iPad 分栏矩阵仍待人工走查。
- 共享项目 Socket 恢复新增 5 类测试代码，并再次通过修改 Swift 文件语法检查、pbxproj 校验和 `git diff --check`；XCTest 保持豁免，真机触屏矩阵保持待人工验收。
