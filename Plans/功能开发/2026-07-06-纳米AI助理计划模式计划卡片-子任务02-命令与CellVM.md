# 子任务02：命令 + `.planCard` cellType + `NMChatPlanCardCellVM` 状态机

**parent**：[[2026-07-06-纳米AI助理计划模式计划卡片]]
**覆盖 AC**：AC1, AC9（状态基座）
**依赖**：无（基座，可与 T01 并行）

## 输入
- 方案 §5.2 状态机（approvalState：pending/executing/modifying/consumed/disabled）。
- 现有先例：`NMGeneratedAgentCardCellVM`（`NAMIWork/Features/ClawChat/ViewModel/CellViewModels/NMGeneratedAgentCardCellVM.swift`，同为带底部按钮的卡片 + 状态枚举）。
- cellType 枚举：`NAMIWork/Features/ClawChat/ViewModel/NMChatCellViewModel.swift:29`。
- 命令定义：`NAMIWork/Features/ClawChat/Command/NMChatCommand.swift`。

## 步骤
1. **cellType**：在 `NMChatCellType`（:29）新增 `case planCard = "planCard"`；在 `isAICell` 的 switch 里归类（参考 `generatedAgentCard` 归 `false` 分支——卡片不参与 AI 分组折叠）。
2. **CellVM**：新建 `NAMIWork/Features/ClawChat/ViewModel/CellViewModels/NMChatPlanCardCellVM.swift`：
   ```swift
   enum NMPlanCardApprovalState { case pending, executing, modifying, consumed, disabled }
   class NMChatPlanCardCellVM: NMChatAssistantBaseCellVM {
       let runId: String
       let toolCallId: String          // = answerPlan.requestId
       private(set) var planMarkdown: String
       var approvalState: NMPlanCardApprovalState = .pending
       var isLatest: Bool = true
       var canApprove: Bool { approvalState == .pending }   // 按钮可点唯一判据
       init(messageId: String, runId: String, toolCallId: String, planMarkdown: String) {
           self.runId = runId; self.toolCallId = toolCallId; self.planMarkdown = planMarkdown
           super.init(messageId: messageId, cellType: .planCard)
       }
       func updateState(_ s: NMPlanCardApprovalState) { approvalState = s; invalidateHeightCache() }
       func updateMarkdown(_ md: String) { planMarkdown = md; invalidateHeightCache() }
       override var contentHash: Int { planMarkdown.hashValue ^ approvalState.hashValue }
       // calculateHeight：Markdown 内容高度 + 按钮区高度，参考 NMGeneratedAgentCardCellVM
   }
   ```
3. **命令**：在 `NMChatCommand.swift` 新增（注意末尾 switch 无 default，需在相关属性里为新 case 选策略，编译器会强制）：
   ```swift
   case insertPlanCard(messageId: String, runId: String, toolCallId: String, planMarkdown: String, timestamp: Double?)
   case updatePlanCardState(toolCallId: String, state: NMPlanCardApprovalState)
   case updatePlanCardMarkdown(messageId: String, planMarkdown: String)
   ```
4. **cellId 规则**：在 `NMChatCellIdHelper`（`Helper/NMChatCellIdHelper.swift`）加 `planCardCellId(runId:toolCallId:)` → `planCard_{runId}_{toolCallId}`。

## 输出
- `NMChatCellType.planCard` + `NMChatPlanCardCellVM.swift` + 3 条命令 case + cellId helper。

- [ ] CellVM 不含任何网络调用（纯状态）。
