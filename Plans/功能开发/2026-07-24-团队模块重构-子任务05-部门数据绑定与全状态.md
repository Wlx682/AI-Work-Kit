# 子任务 T05：部门数据绑定与全状态

## 输入

- T02 Stores / Service、T03 Directory、T04 UI。
- 共享团队服务 / 当前一级部门直属成员搜索与 Variant 规则。

## 输出

- `NMTeamDepartmentViewModel/Controller` 数据绑定。
- 服务 / 成员首次加载、下拉刷新、分页、完整快照搜索、清空恢复。
- loading / empty / search-empty / error / pagination-error / retry。
- 成员“进入主页”路由；部门服务“雇佣”复用旧智能体安装 / 对话链路，服务卡片非按钮区域零副作用。

## 验收

- 服务来自旧团队共享智能体单列表、所有部门同源；成员只来自当前 org 直属人员。
- 搜索构建完整 snapshot 期间反馈 loading；失败不展示不完整结果。
- 两 Tab 状态独立；分页失败保留已加载项；企业切换清空并丢旧回包。
- 点击雇佣时，已安装直接进入该智能体新对话；未安装通过旧 `agent.install_with_url` 链路安装并更新本地安装态后进入新对话；失败提示且不跳转；服务卡片非按钮区域不触发动作。

## 执行记录

- 新增 `NMTeamDepartmentViewModel`，部门服务 / 成员分别持有 keyword、state、完整快照结果和刷新状态。
- 部门服务使用 `NMTeamScopedAgentStore`，请求契约复用旧团队智能体列表 `available_scopes=ee`，不带 `category_id/organization_id`；成员使用 `NMTeamDirectMemberStore`，只请求当前组织直属人员。
- 两类 Store 内部遍历分页并形成完整 snapshot 后才允许本地搜索；加载期间多次修改关键词，完成时只应用最新值。
- 切换“部门服务 / 成员”时保留各自搜索词、结果和状态，清空服务关键词恢复团队共享完整列表，清空成员关键词恢复当前部门直属成员。
- 首次加载失败显示整页 error + retry；搜索无结果显示 search-empty；刷新 / 内部分页失败保留上一版可见列表并用 Toast 提示。
- 接入下拉刷新、retry、loading / empty / search-empty / error / content 全状态。
- 服务卡片整行没有 selection intent；“雇佣”按钮产生当前服务的 `hireService(agent)` intent，经 Team 容器完成离线 / VIP / 安装信息 / Gateway 门禁，复用 `installAgentWithURL(source: "recommend")`、`handleAgentInstalled` 与新对话导航；成员行仅产生 `employeeWorkspace(member)` intent 并通过 Controller 回调交给 T06/T07 的工作空间路由。
- 企业 key 或部门 generation 不匹配时 Store 返回 stale scope；ViewModel invalidate 清空两类 Store 并丢弃旧 completion。
- 更新 AC5、AC10、AC11、AC12 测试靶点，移除对应 pending。
