# 子任务 06：swarm 任务卡片 + 异常/边界

**WBS**：#8/#9 | **依赖**：子任务04、05

## 目标

处理 `project.sessions` 返回的多专家任务卡片渲染，并收口全部异常/边界态。

1. **swarm 卡片渲染（决策4）**：项目「任务」Tab 会话列表（`NMProjectConversationListViewController`）按 `taskType` 分支——`=="swarm"` 时卡片显示**成员头像叠加 + memberCount**（数据取自 `project.sessions` 二期接口返回的 memberAvatars/memberCount/swarmTaskId）；普通会话照旧。点击目标待产品确认（**P1-Qnew1**，先按「进 PM 会话」实现，留 TODO）。
2. **会话移出拦截**：swarm PM session 调 `project.session.move` 移出主列表 → 后端返回 `INVALID_REQUEST` → Toast「多专家任务会话不支持移出项目」。
3. **异常/边界收口**：
   - 无专家空态：专家团 Tab（子任务04）、@ 浮层（子任务05）——本任务复核齐全
   - 专家安装失败（@/创建）→ 按「创建失败」，Toast 提示，用户重新点击即可（不回滚/不自动重试）
   - 未安装专家被 @ → 后端自动沉淀加入项目专家列表（客户端刷新列表即可）
   - 专家来源/列表接口失败 → Toast + 可重试
   - 云控推荐缺失 → 推荐区静默隐藏

## 验收

- [ ] swarm 卡片正确渲染成员头像+数量；普通会话不受影响（AC9-反：项目内任务不进首页）
- [ ] swarm 会话移出被拦截并 Toast
- [ ] 安装失败提示可重试；未安装@后端沉淀后列表刷新正确
- [ ] 各空态/降级齐全（对照需求 plan §四边界、§五异常矩阵）
- [ ] 编译通过 + 真机验证
