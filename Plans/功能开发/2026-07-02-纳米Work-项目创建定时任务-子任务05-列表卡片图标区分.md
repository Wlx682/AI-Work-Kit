# 子任务 05：列表卡片图标区分（3.5 / D2）

**WBS**：#8 | **依赖**：01

## 目标

自动化任务列表同时展示专家任务与项目任务，靠图标区分类型。

1. **判定 owner**（`NAMIWork/Features/Conversation/MainList/view/NMScheduledTaskCellVM.swift`）：
   - 从 `CronJob` 判定该任务是 project 还是 expert（依据：`agentid` 命中项目 id / 后端返回的 ownerType 字段——**待与服务端确认识别方式**，先按"能取到项目信息则视为 project"占位）。
2. **卡片展示分支**：
   - 专家任务（不变）：左侧 `icon`=专家头像，副标题 `agentName`=「专家名·时间」。
   - 项目任务：左侧=**项目图标**，标题=任务名称，副标题=「项目名·时间」（覆写 `icon`/`agentName` getter 的 project 分支）。
3. **点击行为（关联 I3）**：项目任务点击 → 进入该项目 + 定位到该任务会话（PRD 3.5）；专家任务点击保持原行为。**若点击目标待与服务端/产品最终确认，先按现有"进任务详情"占位并标 TODO**。
