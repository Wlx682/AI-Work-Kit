# 子任务 02：项目 HTTP 仓储

## 输入

- 子任务01 Domain/Mapper
- 现有 `NMEnterpriseAPI` Items、组织、成员、申请接口
- Web `items/detail.item_config.sessions/experts` 兼容契约

## 输出

- async `NMProjectCatalogRepository`
- async `NMProjectTaskRepository`
- async `NMProjectExpertRepository`
- async `NMProjectMemberRepository`
- `NMSimpleRequest` 取消桥接与 Repository 集成测试

## 边界

- 创建项目仍走 Gateway，不在此任务实现。
- 任务/专家未公开的写 Route 仅保留协议 seam；禁止 Gateway 回退或猜 URL。
- HTTP 错误归一化但保留服务端安全 `msg`。

## 验收

- [x] 项目列表/详情、任务、专家、成员均有 HTTP Repository
- [x] 企业项目、任务、专家、成员列表读取不访问 `GatewayService.activeRPC`
- [ ] 请求可随项目 scope 取消
- [x] 成员邀请/移除/审核使用 HTTP，提交后刷新权威列表
- [ ] 覆盖 AC1, AC8, AC10, AC11, AC12, AC13, AC15, AC19

## 当前进度

- HTTP 读取与成员邀请/移除/审核已接入；任务/专家写操作因正式 HTTP Route 未确认而 fail-closed，未猜 URL、未回退 Gateway。
- async 任务支持调用方取消与回包前取消检查；底层 `NMSimpleRequest` 的主动 cancel 桥接及真实接口联调仍待完成。

## 依赖

依赖子任务01；正式任务/专家写接口在子任务09联调。
