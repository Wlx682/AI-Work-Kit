# 子任务 06：项目用例与权限

## 输入

- 子任务01–05
- 需求状态机、GWT、异常矩阵
- 现有 `NMProjectsService` 创建校验

## 输出

- `EnterProjectUseCase`
- `CreateProjectAndReconcileUseCase`
- `LoadProjectTabUseCase`
- `UpdateProjectMembersUseCase`
- `AuditProjectApplicationUseCase`
- `NMProjectDetailState`、权限与 Reducer 测试

## 核心规则

- 创建只调用一次 Gateway，HTTP 仅对账。
- 他人项目进入先连接再 ready。
- 成员 remove 集合强制剔除 owner。
- 未加入公开项目四 Tab 只读。
- 任何异步提交都校验 scope generation。

## 验收

- [x] 创建仍只调用既有 Gateway，HTTP 列表仅用于后续展示
- [x] 连接失败不进入详情且无 personal 降级
- [x] 成员 diff 去重、owner 保护，成功后刷新
- [x] 审核调用 HTTP 并刷新服务端记录
- [ ] 覆盖 AC2, AC6, AC12, AC14, AC15, AC16

## 当前进度

- 进入项目、成员差异和审核流程已集成到现有控制器；共享项目禁止删除项目，企业专家写操作在契约缺失时只读。
- 部分失败后的强制权威回拉、重复审核终态以及未加入公开项目只读态仍需真实接口/团队入口联调。

## 依赖

依赖子任务01–05；完成后解锁 UI。
