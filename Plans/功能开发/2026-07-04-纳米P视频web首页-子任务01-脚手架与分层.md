# 子任务 T01：脚手架与分层基座

**parent**：`Plans/功能开发/2026-07-04-纳米P视频web首页.md`

## 输入
- 技术方案分层架构（Presentation→Domain→Data→Infra）与模块边界。

## 输出
- Vite + React18 + TS 脚手架，ESLint/Prettier/Vitest 配置。
- 目录骨架：`src/{app,pages,components,domain,data,infra,styles}`。
- 数据层抽象：`data/repositories/*`（接口）+ `infra/http`（client）+ `infra/mock`（MSW handlers）。
- 状态基座：Zustand slices（authStore/memberStore/pointsStore 空壳）+ React Query Provider + queryClient。
- 云控缓存工具（localStorage + stale-while-revalidate 封装）。
- 埋点封装壳 `domain/tracking`（track/去重/防抖，逻辑先落，接入后置 T05）。
- CSS Modules + 设计变量（token）基线。

## 验收
- `npm run dev` 起本地、`npm run test` 可跑（含 1 个 smoke 测试）。
- Repository 接口可在 Mock/真实实现间切换（env 开关）。
- 分层 lint 规则：components 不得直接 import http client。

## 依赖
- 无（基座，最先做）。
