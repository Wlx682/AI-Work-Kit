# 子任务 03：创建项目专家区 + 图标弹窗 + 推荐名

**WBS**：#6 | **依赖**：子任务02 | **Figma**：3.1 / 3.3 / 3.6

## 目标

改造一期创建项目流程，新增专家选择区、添加专家弹窗、图标弹窗、推荐项目名展示。

1. **创建页专家区（PRD 3.1）**：命名+指令后新增「专家」部分——专家卡片列表（头像+名称+一句话简介+删除按钮）、「已选 N 个专家」实时计数、底部「添加更多专家」按钮；创建按钮**始终可点**（无专家也能建）。创建时调 `projectCreate(expertAgentIds:)`，商店专家直接安装。
2. **添加专家弹窗 `NMProjectExpertPickerController`（PRD 3.3，新建）**：多 Tab（我的专家 / 专家商店推荐），搜索，勾选；商店专家选中→确认时安装。数据源 = 子任务02 `fetchAvailableExperts()`。**复用** ClawHub Recommend 的列表样式可参考。
3. **图标弹窗（PRD 3.6 / D5）**：入口从设置页迁到「项目名称输入框左侧图标」；点击打开弹窗选颜色+图标（复用 `NMProjectIcon`）；确认后名称框左侧显示所选图标。
4. **推荐项目名（PRD 3.6 / S4）**：名称框下方展示云控推荐项（子任务01 `projectRecommendationInfo()`），点击填入名称+图标；名称框已有内容则替换。
