# 子任务05：审批交互（开始执行）

**parent**：[[2026-07-06-纳米AI助理计划模式计划卡片]]
**覆盖 AC**：AC2, AC7, AC2-反
**依赖**：T01（answerPlan RPC）、T04（Cell 按钮回调钩子）

## 输入
- 方案 §5.4/§5.5 流程一：点开始执行 → 切 executing → `answerPlan(approve:true)` → 成功保持、失败回滚 pending + Toast。
- 现有先例：`NMChatViewController+ClawMaster.swift:84` `handleAgentCardButtonTap`（卡片按钮 → RPC → loading/Toast/状态翻转的完整范式）。
- Toast=`NMToastView`、Loading=`NMLoading`（勿造轮子）。

## 步骤
1. 新建 `NAMIWork/Features/ClawChat/NMChatViewController+PlanCard.swift`（extension，仿 +ClawMaster）。
2. 实现 `handlePlanCardApprove(cellVm:)`：
   - 防连点：`guard cellVm.canApprove`（非 pending 直接 return）。
   - 立即本地切 `updatePlanCardState(.executing)`（按钮移除、显示「开始执行…」）。
   - `Task { @MainActor [weak self] in ... }` 调 `GatewayService.shared.activeRPC?.answerPlan(requestId: cellVm.toolCallId, approve: true)`。
   - 成功：保持 executing（执行流后续由既有 assistant/tool 事件渲染，卡片不回写）。
   - 失败：`updatePlanCardState(.pending)` 回滚 + `NMToastView.show(withStatus:"操作失败，请重试")`。
3. 在 T04 的 Cell 绑定处把 `onApprove` 接到 `self.handlePlanCardApprove(cellVm:)`。
4. **AC7 计划归属优先胶囊**：无需特殊处理——answerPlan 按 toolCallId 走计划链，与当前胶囊模式无关；确认执行链不读 `currentWorkMode` 即可（写一句注释说明）。
5. **AC2-反 旧卡不可审批**：T03 已在插新卡时把旧 pending 翻 disabled；此处 `guard canApprove` 再兜一层。

## 输出
- `NMChatViewController+PlanCard.swift`（approve 分支）+ Cell onApprove 绑定。

## 验收
- [ ] `xcodebuild build` 通过。
- [ ] AC2：点开始执行 → 两按钮移除、显示「开始执行…」、发出 answerPlan(approve:true)。
- [ ] AC7：胶囊切到目标模式后点开始执行，仍按计划链走 answerPlan（不受胶囊影响）。
- [ ] AC2-反：点非最新（disabled）卡片按钮无响应、不发 answerPlan。
- [ ] 失败回滚 pending + Toast；防连点生效。

## 不做
