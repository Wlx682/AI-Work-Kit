# 子任务 T07：工程集成与验收

## 输入

- T01–T06 的生产代码、测试代码和项目文件改动。
- `Plans/自动化测试/2026-07-23-团队组织架构.md`。
- Figma `78-10245`、`78-10101`、`78-9964` 与 AC1–AC16。

## 输出

- 完整 `project.pbxproj` 注册核对：五个生产 Swift 文件进 App target，测试文件仅进 `NAMIWorkTests` target。
- 定向 XCTest、App build、模拟器/可用真机运行结果。
- 企业主链路、非企业隔离、企业切换、快速搜索、下拉刷新、空/错/重试/分页人工走查记录。
- 三页面实现截图与设计差异清单；差异未清零时不宣称完成。

## 验收

- `plutil -lint NAMIWork.xcodeproj/project.pbxproj`、`git diff --check`、定向 `xcodebuild test` 与 App build 通过。
- 在真实 App 中操作“全部员工 → 多级部门 → 叶子成员 → 搜索/清空 → 返回”，监控控制台无崩溃和布局约束错误。
- 非企业账号不可进入且网络记录无 `api/claw/ent/*`；企业切换后旧回调不覆盖新企业。
- 快速搜索仅最后关键字渲染；成员/搜索分页和下拉刷新均验证。
- 三接口参数位置与真实回包映射完成联调；若代理字段与文档不同，只做经回包证实的最小调整并补测试。
- 不保留/提交 Figma token、Geelib token、签名 URL、生成 PNG/JSON/EasyDoc 抓取文件。
- 不运行无必要的 pod install；若必须运行，使用 UTF-8 locale，并将无关 `Podfile.lock`/pod 生成噪音排除在功能提交之外。
