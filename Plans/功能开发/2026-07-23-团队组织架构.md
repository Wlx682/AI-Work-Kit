## 二、背景与目标

- 企业账号从团队首页“全部员工”进入组织架构，在现有 Team 导航栈逐级查看部门与叶子部门直属成员。
- 搜索范围为全租户，参数使用 `keyWord`，输入防抖 300ms；成员/搜索每页 20 条并自动触底分页。
- 部门页与成员页均支持下拉刷新；所有请求使用 generation + enterpriseKey 丢弃陈旧响应。
- 非企业或企业上下文缺失时不可进入、不可发起任何 `api/claw/ent/*` 请求。

## 四、架构概要

| 模块/类 | 职责 |
|---------|------|
| `NMTeamOrgModels` | 递归组织树、成员、分页包、首层展开与路径纯逻辑 |
| `NMTeamOrgRequestParams` | query/body/企业 header 纯参数构造 |
| `NMTeamOrgRequestHandler` | 三个企业接口、业务包校验、模型映射 |
| `NMTeamOrgListViewModel` | 部门状态、首层展开、generation+enterpriseKey 防串 |
| `NMTeamMemberListViewModel` | 直属成员分页、搜索防抖/版本、清空还原、刷新防串 |
| `NMTeamOrgViewController` | 部门列表、逐层下钻、叶子分流、导航栏与状态视图 |
| `NMTeamMemberListViewController` | 成员列表、搜索、头像、分页、刷新、空/错/重试 |
| `NMTeamHomeViewController` | “全部员工”入口闭包与企业上下文校验 |
