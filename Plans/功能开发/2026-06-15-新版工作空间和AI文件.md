## 二、背景与目标

### 业务需求

- **工作空间 Tab**：三级目录 — 专家 → 会话标题 → 产物 / 过程文件（`scope=process` 下钻）

### 成功指标

- 三个 RPC 统一映射为 `NMFileNode`，供列表 Cell 绑定
- 工作空间 L2+ 支持面包屑导航（复用 `BreadcrumbView`）
- 三个 Figma Frame **1:1** 还原（@2x px ÷ 2 = pt）
- 文件预览 / 分享 / 编辑复用旧 `WorkspaceFilePreviewer` 链路
- 旧工作空间模块零改动，新 Tab 可灰度切换

### 非目标（本需求不做）

- **AI 文件 Tab**（含 `filesystem.ws.finals`、新版 `NMAIFilesViewController`）— 保持旧实现
- **用户上传 Tab**（Figma `30371:41535`）— 旧云盘链路
- 删除或重构旧 `WorkSpace` / `NMAIFilesViewController`
- 搜索、批量操作、移动文件（除非 PRD 后续补充）
- Bonjour / 自动发现

### 模块职责

| 模块 | 职责 |
|------|------|
| `NMGatewayWorkspaceModels` | 三个 RPC 的 DTO |
| `GatewayRPCClient+WorkspaceFS` | `listWSAgents` / `listWSSessions` / `listWSSessionFiles` |
| `NMFileNode` | 统一列表节点 |
| `NMNewWorkspaceDataProvider` | 拉数胶水 |
| `NMWorkspaceNavLevel` | 导航栈 + 面包屑推导 |
| 预览桥接 | `NMWSFileItem → ClawFileItem → WorkspaceFilePreviewer` |

### RPC 对照（已对齐 `Contexts/API/OpenClaw-API.md` §纳米 Work）

| 方法 | 请求参数 | 响应 item 关键字段 | DataProvider |
|------|---------|-------------------|--------------|
| `filesystem.ws.agents` | `offset`, `limit` | `session_key`, `agent_title`, `agent_icon`, `file_count`, `update_time`, `agent_status` | `fetchAgents` |
| `filesystem.ws.sessions` | `agent_id`(=专家`session_key`), `limit`, `before_timestamp?`, `query?` | `session_id`, `session_key`, `title`, `timestamp`, `file_count`, `update_time` + `has_more`, `next_before_timestamp` | `fetchSessions` |
| `filesystem.ws.session_files` | `session_id`, `scope`(final/process), `offset`, `limit` | `NMWSFileItem` + `process_count`, `process_update_time`(scope=final) | `fetchSessionFiles` |

### 已确认的设计决策

| 决策 | 说明 |
|------|------|
| 无 `NMFileNodeDisplay` | UI 直接读 `node.source` + `NMFileNodeFormatting` |
| 面包屑 | ViewModel `navStack`，不挂在 `NMFileNode` |
| 过程文件入口 | `scope=final` 响应的 `process_count` 合成文件夹行，点进后 `scope=process` |
| AI 文件 Tab | 本期不改，继续用旧 `NMAIFilesViewController` |
