# 子任务04：计划卡片 Cell 渲染（Markdown + 两按钮）

**parent**：[[2026-07-06-纳米AI助理计划模式计划卡片]]
**覆盖 AC**：AC1（渲染呈现）
**依赖**：T02（CellVM）、T03（插卡）

## 输入
- Figma 37886-7206（尺寸 ÷2，见 docs/claude/figma-sizing.md）：卡片=Markdown 计划正文 + 底部「修改计划 / 开始执行」两按钮 + 草稿态提示文案。
- 现有先例：`NMChatSwitchFullBloodCell`（`View/Cells/NMChatSwitchFullBloodCell.swift`，带 `onButtonTap` 的卡片）+ `NMGeneratedAgentCardCell`。
- Markdown 渲染：复用聊天现有 Markdown 渲染能力（与 `NMChatTextCell` 同源，勿另引三方）。
- 注册表：`View/NMChatCellRegistrable.swift:15`。
- 颜色一律 `UIColor(hexA:)`；VC 继承规则不涉及（Cell 层）。

## 步骤
1. 新建 `NAMIWork/Features/ClawChat/View/Cells/NMChatPlanCardCell.swift`（继承 `NMChatBaseCell`）：
   - 子视图用 `private lazy var` 闭包初始化（项目约定）。
   - Markdown 正文区（复用 TextCell 的 Markdown 渲染）+ 底部按钮区（两按钮）+ 进行态文案 label。
   - `var onApprove: ((NMChatPlanCardCellVM) -> Void)?`、`var onModify: ((NMChatPlanCardCellVM) -> Void)?`（仿 `NMChatSwitchFullBloodCell.onButtonTap`）。
   - `configure(vm:)` 按 `approvalState` 切换 UI：
     - `.pending`：两按钮显示且可点。
     - `.executing`：隐藏按钮，显示「开始执行…」。
     - `.modifying`：隐藏按钮，显示「等待输入意见」/「提交修改意见…」（文案由 VM 态驱动）。
     - `.consumed`/`.disabled`：隐藏或置灰按钮（`disabled` 置灰不可点）。
   - `prepareForReuse` 清 `onApprove/onModify`。
2. 注册：`NMChatCellRegistrable.swift` defaultRegistrations 加 `.planCard: NMChatPlanCardCell.self`。
3. Cell 绑定：在 dequeue/configure 处（参考 `NMChatCollectionView.swift:227` switchCell.onButtonTap 的绑定位置）把 `onApprove/onModify` 接到 VC 回调（VC 回调实现在 T05）。

## 输出
- `NMChatPlanCardCell.swift` + 注册 + 绑定钩子（回调实现留 T05）。

## 验收
- [ ] `xcodebuild build` 通过。
- [ ] AC1：计划卡片按 Markdown 正确渲染（标题/分节/要点），底部两按钮存在。
- [ ] 尺寸对 Figma（÷2）；颜色用 `UIColor(hexA:)`。
- [ ] UI 走查：截图或标 manual-only（对齐"默认不启模拟器"）。

## 不做
- 按钮点击的业务处理（answerPlan 调用）在 T05；修改态输入框在 T06。
