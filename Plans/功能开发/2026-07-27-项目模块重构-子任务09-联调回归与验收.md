# 子任务 09：联调回归与验收

## 输入

- 子任务01–08
- 自动化测试 Plan AC1–AC20
- 正式任务/专家 HTTP 写契约
- Xcode / Swift tools 6.2 环境

## 输出

- 真实 Items、project-token、Gateway 项目 Socket 联调
- 任务/专家正式 HTTP Adapter
- UT/IT/UI 执行报告
- iPhone/iPad 设计走查与偏差清单
- 回滚开关与生命周期清理验证

## 必测场景

1. 本人项目连接池不新增。
2. 他人项目独立 Socket，失败不回退 personal。
3. 同 VIM 的项目 A/B 不串事件。
4. A→B 快切旧 HTTP/Token/Socket 全丢弃。
5. 登出/切企业/切环境清理全部项目上下文。
6. owner 不可删除，未加入项目只读。

## 验收

- [ ] AC1–AC20 全部通过
- [ ] 所有新增 UT/IT 100% 通过，无 flaky retry
- [ ] 新增 Domain/Data 覆盖率 ≥ 85%
- [ ] Figma 走查完成并有可审计结果
- [ ] 未发现项目 personal 串线或 Token 串用

## 依赖

依赖子任务01–08；若任务/专家正式写契约仍缺失，只阻塞对应真实联调，不得用 Gateway 替代。

## 当前阻塞

- 正常工程构建首先被 `OpenClawKit` 的 Swift tools 6.2 要求阻断（本机 Xcode 16.4 / Swift 6.1.2）。
- 临时兼容性探测越过包清单后，又在既有桥接头依赖 `BRCommonModules/UIColor+BRHex.h` 缺失处停止；探测后已恢复包清单为 6.2。
- 因此当前仅确认全部变更 Swift 文件通过 `swiftc -parse`、`git diff --check`；UT/IT/UI、覆盖率、真机与集成对稿均未宣称通过。
- 任务/专家正式 HTTP 写 Route 仍缺失，当前实现按计划 fail-closed。
