## 二、背景与目标

### 业务需求

- **工作空间 Tab**：三级目录 — 专家 → 会话标题 → 产物 / 过程文件
  - L3 产物：`filesystem.ws.session_files` + `scope=final`
  - 过程文件：API 在 `scope=final` **首页 items** 返回 `is_dir: true` 文件夹行，点进后 `scope=process`

### 成功指标

- 三个 RPC 统一映射为 `NMFileNode`，供列表 Cell 绑定
- 工作空间 L2+ 支持面包屑导航（复用 `BreadcrumbView`）
- 三个 Figma Frame **1:1** 还原（@2x px ÷ 2 = pt）
- 文件预览 / 分享 / 编辑复用旧 `WorkspaceFilePreviewer` 链路
- 旧工作空间模块零改动，新 Tab 可灰度切换

### 非目标（本需求不做）

- **AI 文件 Tab**（含 `filesystem.ws.finals`、新版 AI 文件 UI）— 保持旧实现
- **用户上传 Tab**（Figma `30371:41535`）— 旧云盘链路
- 删除或重构旧 `WorkSpace` / `NMAIFilesViewController`
- 搜索、批量操作、移动文件（除非 PRD 后续补充）

### RPC 对照（已落地）

| 方法 | 请求 | 响应要点 | DataProvider |
|------|------|---------|--------------|
| `filesystem.ws.agents` | `offset`, `limit` | `session_key`, `agent_title`, `agent_icon`, `file_count`, `agent_status` | `fetchAgents` |
| `filesystem.ws.sessions` | `agent_id`(=专家`session_key`), `limit`, `before_timestamp?`, `query?` | `has_more`, `next_before_timestamp`, item:`file_count` | `fetchSessions` |
| `filesystem.ws.session_files` | `session_id`, `scope`(final/process), `offset`, `limit` | 混合 `items`：文件行 **或** `is_dir`+`name`+`count` 文件夹行；`total_count` | `fetchSessionFiles` |

### `session_files` 混合列表示例（`scope=final` 首页）

```json
{
  "items": [
    {
      "is_dir": true,
      "name": "过程文件",
      "count": 10,
      "update_time": 1718448000,
      "session_id": "sess_xxx"
    },
    {
      "id": 419,
      "file_name": "report.pdf",
      "scope": "final",
      "size": 102400,
      "update_time": 1718448100
    }
  ],
  "total_count": 11
}
```

> 响应层**无** `process_count` / `process_update_time` 元数据；过程入口完全依赖 `is_dir` 文件夹行。

### `NMFileNodeKind` 映射

| 层级 | kind | source | 判定 |
|------|------|--------|------|
| L1 专家 | `.agentFolder` | `.agent` | `NMWSAgentItem` |
| L2 会话 | `.sessionFolder` | `.session` | `NMWSSessionItem` |
| L3 过程文件夹 | `.folder` | `.file` | `NMWSFileItem.isDir == true` |
| L3 文件 | `.file` | `.file` | `NMWSFileItem.isDir == false` |

- L3 文件夹展示名：`NMWSFileItem.displayName`（`name` 为空时兜底「过程文件」）
- L3 文件夹节点 id：`folder:process:{sessionId}`
- **不再**用 `.sessionFolder` 表示 L3 过程目录（与会话文件夹语义分离）

### 设计决策

| 决策 | 说明 |
|------|------|
| 专家主键 | 用 `session_key`，作 sessions 的 `agent_id` 入参 |
| 会话分页 | 游标 `before_timestamp`，不用 offset |
| 过程文件入口 | `scope=final` 首页 items 中 `is_dir: true` 行；下钻 `scope=process` |
| 条目模型 | `NMWSFileItem` 统一解码文件行与文件夹行；请求参数保留 `NMWSSessionFileScope`（final/process） |
| 条目 scope 字段 | **已从 `NMFileNode` 移除**；仅 DTO `NMWSFileItem.scope` 保留（文件行） |
| AI 文件 | 本期不改，无 `filesystem.ws.finals` 客户端封装 |
| 面包屑 | ViewModel `navStack`，不挂在 `NMFileNode` |

### 导航层级（ViewModel 用）

```swift
enum NMWorkspaceNavLevel: Equatable {
    case root
    case agent(sessionKey: String, title: String)
    case session(agentSessionKey: String, agentTitle: String,

    case processFiles(sessionId: String, title: String)
}
```
