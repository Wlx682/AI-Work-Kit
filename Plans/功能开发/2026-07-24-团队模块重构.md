## 二、背景与目标

- 把现有团队首页和组织架构整合为“部门 / 专家”统一团队入口。
- 复用已有企业接口与 UI 资产，新增可测试 Team Service Adapter 与 scope 状态。
- 保证部门 / 员工 / 企业数据不串；部门服务“雇佣”复用旧安装 / 对话链路，专家“+”复用旧教练入口，其余视觉-only 控件零副作用。
- 在不新增服务端搜索 API 的前提下，用共享团队服务完整快照与当前部门成员完整快照实现各自范围内搜索。

## 四、架构概要
