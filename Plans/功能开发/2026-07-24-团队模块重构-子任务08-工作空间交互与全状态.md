# 子任务 T08：工作空间交互与全状态

## 输入

- T05 成员入口、T06 Workspace / Project VM、T07 UI。
- 既有 `NMClawSkillDetailPopupController` 与 Popup presentation 约定。

## 输出

- 四 Tab 数据绑定、分页、刷新、loading / empty / error / retry。
- 技能 Cell → 既有技能详情弹窗，关闭后保持技能 Tab。
- 项目“查看”、公开项目只读详情、详情底部“申请加入”与工作空间底部邀请选择器 presentation / 反馈。
- 智能体 / 任务 / 项目卡片视觉-only 零副作用；团队专家“+”复用旧专家教练入口。
- 企业切换关闭旧技能 / 邀请弹层并清选择。

## 验收

- 项目卡片不进详情，仅操作按钮提交申请；申请 / 邀请文案与状态不混淆。
- 技能复用既有弹窗和使用逻辑，不新建详情 UI。
- 四 Tab 成功 / 空 / 失败互不清除；分页失败保留数据。
- 企业切换时旧弹层 / 选择器关闭，所有旧 scope 回包丢弃。

## 执行记录

- `NMTeamWorkspaceViewController` 新增真实 `NMTeamWorkspaceViewModel` 初始化入口，成员行从叶子部门页进入对应员工工作空间。
- 四 Tab 绑定独立的 agent / skill / task / project 数据和状态；首次按需加载、切换缓存、下拉刷新、尾部预加载、空态、错误态和重试均已接通。
- 智能体使用 `his_public + team_user_qid + available_scopes=ee`；技能 / 任务使用 `his_public + team_user_qid`；项目使用 `items/list_public`，UI 映射与 Web 端字段兼容规则一致。
- 技能行直接构造 `NMClawSkillCellVM` 并展示既有 `NMClawSkillDetailPopupController`，未新增详情页。
- 项目整卡保持零 selection，“查看”按钮打开公开项目详情；详情任务 / 专家 / 成员无交互，知识可下钻 / 预览且无编辑入口；底部按钮按 join 状态展示“申请加入该项目 / 申请中… / 审批中 / 重新申请加入”，已加入隐藏。
- 新增 `NMTeamProjectInvitePopupController`，复用 `NMPopupViewController`；候选项目只保留当前用户可管理且目标员工尚未加入的项目，失败校验 fail-closed，支持选择、提交和失败重试。
- 智能体 / 任务 / 项目卡片的选择策略返回 `nil`；技能返回 `openSkill`。
- 2026-07-27 变更：团队专家“+”由不可交互改为复用旧专家教练入口，完整保留离线、VIP、新旧版本与 iPad 分支。
- 工作空间和邀请弹层在 `viewWillAppear` / App 回到前台时检查企业 key；不一致时清空 VM、使旧回包失效、关闭技能 / 邀请弹层并退出旧工作空间。

## 交互矩阵

| 元素 | 点击结果 | 副作用 |
|------|----------|--------|
| 员工智能体卡片 | 无 | 不进详情、不雇佣 |
| 员工技能行 | 既有技能详情弹窗 | 关闭后仍停留技能 Tab |
| 员工任务卡片 | 无 | 不进任务详情 |
| 员工项目卡片 | “查看” | 进入公开项目只读详情 |
| 详情“申请加入” | `items/apply_join` | 按 `item_uuid` 防重；已加入隐藏；失败可重试 |
| 底部“邀请加入项目” | 项目选择 Popup | `items/invitation_join`；候选先校验成员 |
| 团队专家“+” | 旧专家教练入口 | 离线拦截、VIP 门禁、新旧版本 / iPad 兼容 |

## 全状态

| 状态 | 四 Tab 列表 | 项目申请 | 项目邀请 |
|------|-------------|----------|----------|
| loading | 共享 loading 容器 | “申请中…”禁用 | “邀请中…”禁用 |
| content | 各 Tab 独立缓存 | 列表“查看” / 详情底部“申请加入” | 可选项目 + “发送邀请” |
| empty | “暂无{Tab}” | — | “暂无可邀请项目” |
| error | 错误文案 + 重试 | “重试申请” | 错误文案 + 重试 |
| 分页失败 | 保留已加载数据并 Toast | — | 成员校验失败项目隐藏 |
| 企业切换 | 清四 Tab / 回包失效 | 清申请状态 | 清选择、关闭弹层 |
