# 子任务 T04：状态机与防串

## 输入

- T02 模型/参数、T03 RequestHandler。
- T01 的 loader、企业 key provider 与搜索调度器测试接缝。
- 既有 Team generation + enterpriseKey 陈旧响应保护模式。

## 输出

- 新增 `NAMIWork/Features/Team/Org/NMTeamOrgViewModel.swift` 并注册到 App target。
- `NMTeamOrgListViewModel`：根/子部门加载、状态、重试、刷新与防串。
- `NMTeamMemberListViewModel`：直属成员分页、全租户搜索、300ms 防抖、清空还原、空/错/重试、刷新与防串。
- 可注入 loader、`currentEnterpriseKeyProvider` 与搜索调度器。

## 验收

- 非企业/企业快照缺失时 loader 调用次数为 0。
- 每次 reload、刷新、新搜索、清空均推进 generation；回调同时校验 generation 与实时 enterpriseKey。
- 快速搜索仅最新 token 可渲染；空白关键字不发搜索请求并还原直属成员。
- 分页从 pageNum=1 开始、pageSize=20，按稳定成员 ID 去重追加，累计达到 total 后停止。
- 首屏失败是整页 error；分页失败保留已有 items 并可重试；成员空与搜索空使用不同状态。
- T01 中 ViewModel、IT-201、IT-202、分页、搜索与刷新测试转绿。
