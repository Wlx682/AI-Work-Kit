## 二、背景与目标

- **业务目标**：企业项目任务列表以 Gateway 运行会话为可进入事实源；进入任务前绑定正确会话，确保历史与消息不串项目、不串任务。
- **Socket 目标**：共享项目在进入详情前创建项目 Socket；项目内列表、绑定、历史和发送复用同一 `gatewayKey`；断线同键重连。
- **端一致性目标**：iPhone 与 iPad 使用相同项目、Gateway、会话身份进入对话。
- **非目标**：App 主任务页过滤/路由、完整项目权限模型、Web、`chat_source`、富文本编辑器；专家编辑仅按确认规则移除企业只读分支并补项目 Gateway 写入。

## 三、设计稿与交互范围

本需求不新增视觉体系，沿用项目任务列表与对话页现有组件。需要补齐的状态包括：

- 项目任务列表：加载、正常、空、Gateway/Socket 错误与重试；
- 对话入口：会话绑定中、绑定失败、历史失败、无权限/会话失效；
- 输入区：绑定或重连完成前不可发送，失败时保留草稿。

## 四、架构概要

| 模块 | 职责 |
|------|------|
| `NMProjectSessionMetadataMerger` | 以运行会话形成列表，HTTP 只覆盖展示元数据 |
| `NMEnterpriseProjectConversationLoader` | 编排 Gateway 硬依赖与 HTTP 软依赖，处理分页和错误 |
| `NMProjectGatewayResolver` / Pool | 共享项目入口前建连、项目级复用和同键重连 |
| `NMGatewayProjectSessionBinder` | 调用并校验 `sessions.set.current.session` |
| `NMProjectChatEntryCoordinator` | 串行绑定、last-wins、生成已绑定目标 |
| iPhone / iPad Project Controller | 只在项目连接与会话绑定成功后进入 Chat |
| Chat / Push Helper | 使用显式项目、Gateway、会话上下文加载历史和发送 |
