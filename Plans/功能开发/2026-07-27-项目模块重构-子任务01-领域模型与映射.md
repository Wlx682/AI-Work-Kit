# 子任务 01：领域模型与映射

## 输入

- 技术方案 §五数据模型、§七 API Schema
- 测试计划 UT-001、UT-003–007、UT-040
- 现有 `NMEnterpriseProject`、`NMProjectRecord`、`NMProjectExpertRow`

## 输出

- `NMProject`、`NMProjectTask`、`NMProjectExpert`、`NMProjectMember`、`NMProjectScope`
- HTTP/Gateway DTO → Domain Mapper
- item_config 字符串/对象兼容解析
- 首批 Mapper 单元测试与固定 fixture

## 边界

- 不发网络请求。
- 不实现 Gateway 建连。
- DTO 不进入 Presentation。
- 任务缺 session 标识时不猜测并降级为仅展示；专家缺唯一 ID 时按 Web 端使用名称/序号生成稳定展示标识，完全空行才丢弃。

## 验收

- [x] HTTP 项目字段完整映射 item/project/vim/owner/public
- [x] item_config string/object/坏 JSON 均已编写测试
- [x] 任务缺 session 标识仅展示且不推导；专家空行丢弃、缺 ID 兼容 Web
- [x] 新 Domain 不依赖 `[String: Any]`
- [ ] 覆盖 AC1, AC8, AC10, AC11, AC19

## 当前进度

- Domain、DTO Mapper 与测试用例已落地，全部变更 Swift 文件通过 `swiftc -parse`。
- XCTest 尚未执行：正式工程要求 Swift tools 6.2；兼容性探测又被既有 `BRCommonModules/UIColor+BRHex.h` 缺失阻断。

## 依赖

无；完成后解锁 02、03、05。
