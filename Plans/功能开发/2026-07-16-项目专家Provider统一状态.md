## 二、目标与非目标

- 目标：专家 Tab 列表、输入框当前专家、已添加专家弹窗列表使用同一个项目级 Provider 状态。
- 目标：Provider 提供观察者接口，状态变化后通知其他使用模块。
- 目标：`NMProjectAddedExpertPopupController`、`NMModelComponent` 不直接依赖 Provider，由调用方同步输入和回写输出。
- 非目标：修改专家接口契约、弹窗 UI 或输入框视觉样式。

## 三、架构概要

| 模块/类 | 职责 |
|---------|------|
| `NMProjectExpertProvider` | 专家列表、选中专家、缓存、网络更新、弱观察者 |
| `NMProjectTeamViewController` | 直接订阅 Provider 并通过 Provider 增删查 |
| `NMProjectAddedExpertPopupController` | 接收列表快照，通过回调上报列表变化 |
| `NMModelComponent` | 保持纯展示接口，由详情页根据 Provider 选中态调用 `applyAgent` |
| `NMProjectDetailViewController` | 负责弹窗、输入框与 Provider 的双向同步 |
