# 子任务 T02：企业服务与作用域存储

## 输入

- T01 测试接缝；技术方案 ADR-1/2/3/10。
- `NMEnterpriseAPI.swift`、`NMTeamOrgModels.swift`、现有企业模型。

## 输出

- `NMTeamEnterpriseProviding` 与 `NMTeamEnterpriseService` Adapter。
- `NMTeamRemoteListState`、`NMTeamRequestScope` 与三重回调 guard。
- `NMTeamScopedAgentStore`、`NMTeamDirectMemberStore`：完整分页、去重、终止护栏、本地搜索。

## 验收

- 部门服务参数复用旧团队智能体列表：`available_scopes=ee`，不带 `category_id/organization_id`。
- 成员搜索只用同 org 的 `org_member_list` 完整快照，零 `search_member/include_sub` 调用。
- Store 不把不完整快照当搜索成功；重复页 / 空页 / 不增长不会死循环。
- enterpriseKey/scopeKey/generation 任一不匹配均不写状态。

## 依赖

- T01。

## 覆盖 AC

AC2, AC5, AC8, AC9, AC11, AC12, AC21, AC23

## 不包含

- 不实现 UI，不拆分整个 `NMEnterpriseAPI.swift`，不新增后端接口。

## 续做

`/resume plan=Plans/功能开发/2026-07-24-团队模块重构-子任务03-目录领域与导航.md`

## 执行记录

- 部门服务 options 复用旧团队智能体请求，只设置 `available_scopes=ee` 与分页参数；2026-07-27 需求变更后已移除无用途的 Agent list `organizationID` 扩展。
- 新增 `NMTeamEnterpriseProviding` / `NMTeamEnterpriseService`，在发送前校验当前企业身份，统一封装共享团队服务和当前部门直属成员请求。
- 新增 `NMTeamRemoteListState`、`NMTeamRequestScope`、通用完整快照 Store、共享 Team Agent / DirectMember Store；覆盖分页去重、重复 cursor、空页/无增长、页数上限和 enterpriseKey/scopeKey/generation 三重回包隔离。
- 当前部门成员 Store 只使用 `org_member_list` 构建完整快照并本地搜索，不调用 `search_member` / `include_sub`；不完整快照不会返回本地搜索结果。
- 企业列表统一响应解析兼容 `list: null`，归一化为空数组并保留 `total/npt`；非数组的异常值仍按协议错误处理，并补充空列表与非法类型回归用例。
- `xcrun swiftc -parse`、`plutil -lint project.pbxproj`、`git diff --check` 通过；App generic iOS build 与测试目标 `build-for-testing` 均成功。
- 未运行 XCTest：遵循既有物理设备执行约束，本阶段只验证生产目标和测试目标可编译。
