# 子任务 03：项目 Socket 路由

## 输入

- ADR-001
- 子任务01 `NMProject`
- `NMGatewayConnectionPool`、`NMChatGatewayAccessStore`
- Web `enterprise-gateway-pool.ts`

## 输出

- `GatewayRegistration.connectionQueryItems`
- `NMProjectGatewayEndpointBuilder`
- `NMProjectGatewayKeyBuilder`
- `NMProjectGatewayResolver`
- Resolver/Endpoint/Pool 单元与集成测试

## 核心规则

1. owner == current → personal，Pool 调用 0。
2. owner != current → `project:<env>:<tenant>:<vim>:<projectId>`。
3. 目标 URL 携带 `project_id`；非 VIM host 再携带 `vm_id`。
4. owner/current/vim/project 缺失 fail-closed。
5. 建连失败只返回错误，不得回退 personal。

## 验收

- [ ] UT-010–019、IT-010、IT-011、IT-016、IT-017 通过
- [x] 同 VIM 不同项目 key 不同
- [x] 同项目通过现有连接池按稳定 key 建连/复用
- [ ] 连接池上限与 LRU 未回归
- [ ] 覆盖 AC3, AC4, AC6, AC18

## 当前进度

- Resolver/Endpoint/Key 已实现：本人项目返回 personal；他人项目使用 `env + tenant + vim + projectId` 独立 key，建连失败不降级。
- iPhone/iPad 的项目详情和设置入口均先 resolve，再注入显式 Gateway；测试已编写但尚未执行。

## 依赖

依赖子任务01；完成后解锁子任务04。
