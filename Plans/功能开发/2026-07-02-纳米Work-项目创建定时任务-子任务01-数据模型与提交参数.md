# 子任务 01：数据模型与提交参数

**WBS**：#4 | **依赖**：无（最先做）

## 目标

在现有定时任务表单态与参数构造上做增量，让"项目任务"与"专家任务"共用一套模型，仅靠 owner 分支区分。不含 UI、不含入口改造。

1. **`NMScheduledTaskModel` 扩展**（`NAMIWork/Features/Conversation/Create/NMScheduledTaskModel.swift`）：
   - 新增 `enum NMScheduledTaskOwnerType { case expert; case project }`。
   - 新增字段 `var taskOwnerType: NMScheduledTaskOwnerType = .expert`（默认 expert，保证现有流程零变化）。
   - 新增 `var projectId: String?`（project 任务冗余保存项目 id，供 @ 数据源/跳转/列表卡片"项目名"）。
   - `isValidForSubmit`（现第 141 行）：project 任务校验改为 `projectId 非空 + prompt 非空`（不再要求 clawId/agentName，因为 project 任务把 projectId 当 agentId 传；expert 分支保持原逻辑）。
   - `navTitle`：两种 owner 均可复用"创建自动化任务"，暂不区分（如设计要求区分再改）。
2. **`makeSubmitParams` 扩展**（`NAMIWork/Features/Conversation/Create/NMScheduledTaskScheduleBuilder.swift`，现第 76/110 行）：
   - project 分支：`params["agentId"] = model.projectId`（P0-2：项目=智能体）。
   - 预留 owner 字段：`params["ownerType"] = model.taskOwnerType == .project ? "project" : "expert"`（**占位**，加注释说明"待与服务端商定字段名/取值，未定则可安全移除"）。
   - expert 分支：完全不变（`agentId=clawId`）。
