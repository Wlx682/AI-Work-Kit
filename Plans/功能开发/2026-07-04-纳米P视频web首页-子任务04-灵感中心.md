# 子任务 T04：灵感中心（Tab + 双形态 + 内容卡片）

**parent**：`Plans/功能开发/2026-07-04-纳米P视频web首页.md`
**Figma**：node 2-4227 灵感中心区（分组横滑：左标题区 250 + 右竖版卡片 214×382）

## 输入
- cloudConfigRepo（Tab 列表）+ 内容接口契约（瀑布流分页 / 分组横滑）。
- 骨架屏组件（T03 SkeletonLayer）。

## 输出
- `InspirationCenter`：Tab 栏（默认选排序最前）、按云控 `layout` 渲染形态、Tab 切换防抖 300ms 回顶取消在途。
- `WaterfallLayout`：多列错落 + 触底分页（useInfiniteQuery）+ 末页「没有更多了」。
- `GroupScrollLayout`：子分组堆叠 + 横滑翻页（首屏隐左/末屏隐右不循环）+ 空组隐藏。
- `ContentCard`：封面/标题、悬停视频静音自动播放 + 浮现一键同款、两区互斥跳转携带参数。

## 验收
- Tab 空退化单「发现」；某 Tab 内容空 Inline「暂无内容」；子分组无作品整组隐藏。
- 形态云控驱动不写死；Tab 切换回顶 + 防抖取最后。
- 卡片悬停预览/移出即停；一键同款与卡片主体互斥跳转。

## 依赖
