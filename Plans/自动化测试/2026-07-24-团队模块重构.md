## 〇、TDD 与项目执行约束

- 本 Plan 定义外层验收测试；开发时先落测试接缝与测试代码，再完成实现使其转绿。
- ViewModel 依赖 `NMTeamEnterpriseProviding` 桩，不触发真实企业网络；手动持有 completion 验证 generation / enterpriseKey / scopeKey 防串。
- 作用域 Store 使用确定性桩分页，覆盖 total、重复页、空页、不增长页与中途失败。
- UI 行为用 coordinator spy / action spy 验证；部门服务雇佣覆盖“已安装直达 / 未安装成功 / 安装失败 / 防重复”，其余“视觉-only”必须断言零导航、零请求、零状态变化。
- 本项目默认**不主动运行 XCTest**：`mars.framework` 只有 iOS 真机 arm64 切片，模拟器链接不可用。只有用户明确要求执行 XCTest 时，才读取已连接 iPhone destination ID 后运行真机测试。
- 常规开发验收优先：`generic/platform=iOS` 真机构建 → 安装到已连接 iPhone → 页面操作 / 截图走查。

### 可测试性接缝

1. `NMTeamEnterpriseProviding` 协议 + 完成回调桩。
2. `NMTeamRequestScope(enterpriseKey:scopeKey:generation:)` 与可注入 `currentEnterpriseKeyProvider`。
3. `NMTeamScopedAgentStore` / `NMTeamDirectMemberStore` 暴露只读 snapshot、load/search intent 和 state。
4. `NMTeamNavigationCoordinating` spy：记录 department/workspace/skill/invite route。
5. `NMTeamProjectActionState` 与可注入 apply/invite loader。
6. 对搜索防抖使用可注入 scheduler 或测试模式立即调度，不依赖真实 sleep。
