## 四、集成测试清单（RTL + MSW）

| ID | 场景 | 依赖 | Mock 策略 | 期望 |
|----|------|------|-----------|------|
| IT-101 | 四区块独立骨架先到先渲染 | 三云控接口 | MSW 分别延迟不同时长 | 先返回区块先出真实内容 |
| IT-301 | 登录后仅刷新导航栏右侧 | 登录+会员+积分接口 | MSW 登录成功 | 导航栏右侧变、其余区块 DOM 不变 |

| IT-1001 | 积分/会员解耦 | 余额失败+会员成功 | MSW 余额 500、会员 200 | 余额 `--`，CTA 仍按会员态、点击区可用 |
| IT-1301 | 失败/超时可重试 | 内容接口 | MSW 500 / 延迟>10s | Inline 重试，点重试重新拉 |
| IT-1501 | 退出 token 失效仍成功 | 退出接口 | MSW 退出 401 + 本地 token 已清 | 走成功分支刷新未登录态 |
| IT-1702 | 面板分页 | 明细接口 | MSW 多页 + 末页 | 触底加载、末页「没有更多了」、空态文案 |
| IT-1901 | 缓存先渲染后刷新 | 云控接口 | 预置 localStorage 缓存 + MSW 新数据 | 先渲染缓存 → 刷新后更新 |
