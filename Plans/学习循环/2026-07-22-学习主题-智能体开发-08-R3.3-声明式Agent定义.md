# 学习主题：R3.3 声明式 Agent 定义

## 一、学习主题

| 项 | 内容 |
|----|------|
| 本轮主题 | R3.3：把 Agent 的角色、工具、边界和验收从 Python 控制流中提取为可版本化声明。 |
| 已有基础 | Orchestrator 已是 LangGraph 图；R3.2 已有统一 trace/eval 契约；Team 保留独立角色和 A2A 消息。 |
| 本轮目标 | 能判断哪些内容应写为声明，哪些必须留在代码，并为一个最小 Agent 定义选定格式与加载边界。 |
| 非目标 | 不立即迁移 Team 图、不引入新的云平台、不将安全判断简化成提示词文本。 |
