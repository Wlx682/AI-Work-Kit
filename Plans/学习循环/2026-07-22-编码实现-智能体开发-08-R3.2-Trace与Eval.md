# 编码实现：R3.2 Trace 与 Eval

## 八、编码实现

| 任务 | 输入 | 产物 | 验收 |
|------|------|------|------|
| 运行结果告警 | 用户的“默认成功但告警”决策 | `RunResult.warnings` | trace 写入失败不改变 `succeeded` |
| Trace 持久化 | 标准化 `RunResult` | `agent/trace_store.py` | 每个 run 一个 JSON，可读取还原 |
| Runtime 接入 | LangGraph 运行结果 | `LangGraphRuntime._persist_trace()` | 成功与失败运行均尝试保存 |
| 离线 eval | mock 能力层 | `agent/tests/test_runtime.py` | 正常、重规划、失败与告警语义均通过 |

## 九、代码产物

| 产物 | 路径 | 说明 |
|------|------|------|
| Trace 存储 | `agent/trace_store.py` | 每个 run 保存为带 schema 版本的 JSON，并可还原为 `RunResult`。 |
| 非致命告警 | `agent/runtime.py` | `RunResult.warnings` 保持旧调用方兼容，且不改变 `succeeded`。 |
| Runtime 接入 | `agent/langgraph_runtime.py` | 成功与失败结果均尝试保存；落盘错误转为 `trace_persist_failed` warning。 |
| CLI 告警 | `agent/main.py` | 将非致命 warning 显示在终端。 |
| 离线评估 | `agent/tests/test_runtime.py` | 覆盖成功、重规划、规划失败、trace 保存失败四类行为。 |

验证结果：`python3 -m unittest discover -s agent/tests -v` 通过 5 项；`python3 -m compileall -q agent` 与 `git diff --check` 通过。
