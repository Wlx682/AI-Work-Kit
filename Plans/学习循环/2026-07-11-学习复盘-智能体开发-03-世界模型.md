## 十一、复盘

| 维度 | 内容 |
|------|------|
| 已掌握 | 世界模型是行动前预测，不是安全规则也不是工具反馈；要从记忆中读取历史、需求、架构、边界、盲区、上一轮复盘来推演后果；能区分世界模型（预测）vs 工具反馈（事实）vs 记忆（输入） |
| 未掌握 | 规避动作容易写成"禁止 X"而不是"必须做 Y"；世界模型应先预测多种策略的后果再让 System 2 选择，而不是直接默认一种；边界和盲区还不习惯显式列出 |
| 误区 | 把"禁止读取外部上下文"当作规避，实际应该是"必须注入当前项目上下文"；把"禁止空项目"当作唯一选择，但世界模型应列出多种策略让 System 2 选 |
| 最有价值的一点 | 世界模型不只是"预测会出错"，它要先生成候选策略，再用预测比较每种策略的后果，让 System 2 做出更好的选择 |

### 本轮核心结论

```text
世界模型的职责是：
1. 从记忆读取历史、需求、架构、边界、盲区、上一轮复盘。
2. 在行动前预测每个候选计划的后果。
3. 不是只预测"会出错"，而是比较多种策略的后果。
4. 把预测结果交给 System 2 做选择，而不是自己做决定。
5. 规避动作要写成"必须做 Y"，而不是只写"禁止 X"。
```

### 仍需补练的最小点

```text
规避动作的正向表达：
  ❌ 禁止读取外部上下文
  ✅ 必须注入当前项目上下文；禁止读取非本项目上下文

多策略比较：
  世界模型应为每个候选方案预测后果，让 System 2 选择，而不是跳过比较直接默认一种。

边界/盲区显式声明：
  "不知道"本身是有价值的，但要养成习惯——每次都列出，而不是跳过。
```
