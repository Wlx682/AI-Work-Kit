# 编码实现：R3.3 声明式 Agent 定义

## 八、编码实现

| 任务 | 产物 | 验收 |
|------|------|------|
| 定义 loader | `agent/agent_definition.py` | JSON 字段、prompt 文件和工具名均被校验后才形成不可变 `AgentDefinition`。 |
| 结构化策略 | `agent/definitions/general-assistant.json` | 定义 Agent 身份、目标、工具 allowlist 与验收标准。 |
| 角色说明 | `agent/prompts/general-assistant.md` | 长说明与机器策略分离，便于人审阅。 |
| Runtime 接入 | `agent/langgraph_runtime.py` | 运行事件带 `agent_id`；规划、执行和反思消费已校验定义。 |
| 权限交集 | `agent/capabilities/act.py` | 先过滤到定义 allowlist，再调用 `safety.py` 最终审核。 |
| 离线 eval | `agent/tests/test_agent_definition.py` | 覆盖默认加载、未知工具拒绝和 allowlist 过滤。 |
| Team 角色定义 | `planner`、`predictor`、`executor`、`reviewer` 的 JSON/Markdown 定义 | 每个 role 加载自己的策略，并将其传入共享 capability。 |
| 多角色离线 eval | `agent/tests/test_role_definitions.py` | 覆盖四个默认 role 的定义加载和 capability 入参传递。 |

## 九、代码产物

| 产物 | 说明 |
|------|------|
| `AgentDefinition` | runtime 读取的不可变策略对象，不拥有 LangGraph 控制流。 |
| `general-assistant.json` | 标准库 JSON 可解析的结构化元数据。 |
| `general-assistant.md` | 人可读的角色行为说明。 |
| 四角色定义 | Planner/Predictor/Executor/Reviewer 的身份、目标、工具边界和验收。 |
| 11 项离线测试 | 原有 runtime/LLM 回归 + 单/多角色声明定义契约。 |

验证结果：`python3 -m unittest discover -s agent/tests -v` 通过 11 项；`python3 -m compileall -q agent` 与 `git diff --check` 通过。
