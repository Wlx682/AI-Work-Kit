### 第一课：智能体不是“一次回答”，而是“目标循环”

先看图的主线：

```text
用户/高层目标
  -> System 2 慢思考：规划、反思、内在模拟
  -> System 1 快行动：调用工具、生成代码、直接响应
  -> 统一行动空间：代码执行 / 计算机使用 / MCP 工具
  -> 环境和工具返回结果
  -> 记忆保存经验
  -> System 2 根据反馈继续调整
```

这就是智能体开发的第一块地基：目标不会自动变成结果，中间需要一个循环。

最小智能体循环可以写成：

```text
Goal：我要达成什么
Plan：我准备怎么做
Action：我实际做了什么
Observation：环境返回了什么
Reflection：我学到了什么，下一步怎么改
Memory：哪些经验值得保存
```

把它翻译成你这张图：

| 图中部件 | 在循环里的角色 |
|----------|----------------|
| 用户 / 高层目标 | Goal 来源 |
| System 2 慢思考 | Plan + Reflection + Simulation |
| 世界模型 | Action 前的“后果预测” |
| System 1 快行动 | Action 执行器 |
| 安全宪法层 | Action 的边界和审计 |
| 统一行动空间 | Action 能触达的外部世界 |
| MCP 工具总线 | 结构化工具接口 |
| 结构化终身记忆 | Memory |
| A2A 多智能体协作 | 把一个循环扩展成多个角色协作 |

你现在只需要记住一个判断标准：

> 如果系统只回答一句话，它更像 Chatbot；如果系统会围绕目标持续规划、行动、观察、纠错、记忆，它才开始像 Agent。

## 六、问题与澄清

| 问题 | AI 回答 | 是否已懂 |
|------|---------|----------|
| 为什么要分 System 2 和 System 1？ | 因为规划和执行是两种不同负担：规划要慢、要全局；执行要快、要贴近工具和环境。混在一起容易出现“想都没想就乱调用工具”或“永远规划不行动”。 | ✅ |
| 世界模型和真实工具有什么区别？ | 世界模型是行动前的内部预测，真实工具是行动后的外部反馈。前者降低试错成本，后者提供事实校验。 | ✅ |
| 记忆为什么不只是聊天历史？ | 聊天历史是流水，结构化记忆是可检索、可复用、可沉淀的经验。智能体需要知道哪些是当前上下文、哪些是过去案例、哪些是知识、哪些是操作流程。 | ✅ |

### 第 3 题纠偏

正确区分：

```text
世界模型：行动前的内部预测，回答“如果我这么做，可能会发生什么？”
工具反馈：行动后的外部事实，回答“我刚才这么做，真实发生了什么？”
记忆：跨任务复用的经验沉淀，回答“以前类似情况学到了什么？”
```

容易混的点：

- “约束 LLM 不要跑偏”更接近安全宪法层、权限规则、审计和 guardrail。
- 世界模型不是约束器，而是模拟器；它降低试错成本，但不能替代真实工具反馈。
- 记忆不是简单上下文窗口，而是结构化保存后的知识、案例和流程。

### 本阶段结论

本阶段通过。用户已经掌握 L0 总览与目标循环的核心判断：

```text
工具调用本身不等于 Agent。
Agent 至少要有状态、反思、记忆，并围绕目标形成循环。
```
