# 构建实践：智能体开发-04-双系统架构

**创建日期**：2026-07-11  
**状态**：已采纳  
**技术栈**：Python 3.10 + DeepSeek API (OpenAI 兼容)

---

## 一、背景

L0-L2 三轮学习全是概念复述，零代码实践。用户明确要求 build-first：学完要做出一个可运行的智能体。

从 L3 开始，改为构建驱动：每个概念通过编码到真实 Agent 中来验证掌握。

---

## 二、构建目标

对照 Agent OS 架构图，用代码实现每个模块，一一对应：

| 架构图模块 | 代码文件 | 职责 |
|-----------|---------|------|
| 用户/高层目标 → 赋予目标 | `agent/main.py` | 目标循环入口 |
| System 2（慢思考） | `agent/system2.py` | 规划 + 反思 + 计划调整 |
| System 1（快行动） | `agent/system1.py` | 单步执行 + 工具调用（经安全层） |
| 世界模型 | `agent/world_model.py` | 行动前预测 + 风险筛选 |
| 安全宪法层 | `agent/safety.py` | 审核 / 审批 / 拒绝 + 审计日志 |
| 结构化终身记忆 | `agent/memory.py` | 工作 / 情景 / 语义 / 程序记忆 + JSON 持久化 |
| 统一行动空间 | `agent/tools/` | 注册表 + 文件操作 + Shell 执行 |
| LLM 底层 | `agent/llm.py` | DeepSeek API 统一封装 |

---

## 三、构建过程

### 第 1 轮：单系统 MVP (已废弃)

- 两个文件：`main.py` + `tools.py`
- 所有逻辑混在一个 while 循环里
- 问题：docstring 写了 System 1/2，但代码里完全没有分层

### 第 2 轮：双系统拆分

- 把 LLM 调用拆成三个角色：规划者 / 执行者 / 反思者
- System 2 只做规划（纯文本，不调工具），System 1 只调工具
- 每步执行后 System 2 反思：继续 / 调整 / 完成
- 实测验证：路径错误时 System 2 自动调整了后续计划

### 第 3 轮：完整架构重构（当前版本）

- 8 个模块一一对应架构图
- 新增：世界模型（行动前预测 → System 2 调整计划）、安全层（审核 / 审批 / 审计日志）、四种记忆（工作/情景/语义/程序 + JSON 持久化）、工具注册表（动态注册和发现）
- 实测通过：完整任务 "查看 agent 目录的文件结构，告诉我每个模块的职责"

## 四、学到了什么

| 概念 | 之前理解 | 编码后理解 |
|------|---------|-----------|
| 双系统分离 | System 2 想、System 1 做 | System 2 和 System 1 是不同的 LLM 调用，system prompt 不同，System 2 不给工具，System 1 才给工具 |
| 世界模型 | 行动前预测 | 是规划和执行之间的独立环节：拿到计划 → 逐步预测风险 → 有风险则 System 2 重新调整计划 |
| 安全层 | 危险命令拦截 | 三层判定（放行/审批/拒绝）+ 审计日志，嵌入在 System 1 执行链路中，不是 main 里的 if-else |
| 工具注册表 | 一个 dict 映射 | register() 同时注册函数和 JSON schema，工具模块只需调 register_all()，main 不感知具体工具 |
| 结构化记忆 | 聊天历史 | 四种记忆各有生命周期：工作记忆随任务清空，情景记忆持久化供回顾，语义记忆是提炼后的知识 |
| function calling | LLM 有引擎 | 没有引擎，schema 被拼进 prompt，LLM 生成匹配的 JSON，API 层解析后包装返回 |

---

## 五、当前不足

| 不足 | 说明 | 对应 L 层 |
|------|------|----------|
| 语义记忆无自动提炼 | episodic → semantic 的提炼需要人工调用，没有自动触发 | L7 自我纠错 |
| 程序记忆未使用 | 定义了结构但没有写入和检索逻辑 | L7 |
| 单 Agent | 没有 Planner/Executor/Reviewer 角色分工 | L8 多智能体 |
| 世界模型偏保守 | 几乎所有步骤都标风险，导致计划总被调整 | 需要调优 prompt 或加阈值 |
