### 第三课：世界模型是行动前的“沙盘”

世界模型不是“一个神秘的大模型”，也不是“安全规则”。它是 Agent 在行动前做后果预测的能力。

一句话：

```text
世界模型回答：如果我这么做，可能会发生什么？
```

它在目标循环里的位置大概是：

```text
目标 / State / Memory
  -> System 2 生成候选计划
  -> 世界模型预测每个计划的后果
  -> System 2 选择更稳的计划
  -> System 1 执行
  -> 工具反馈返回真实结果
  -> 反思和记忆更新
```

用你刚刚的人员列表例子看：

```text
候选计划 A：
  用一个 loading 字段控制所有加载状态。

世界模型预测：
  下拉刷新、上拉加载更多、首次加载会互相覆盖。
  用户可能看到错误的 loading。
  测试也很难覆盖 noMore 和 refreshError。

候选计划 B：
  分开 loading / refreshing / loadingMore / hasMore / error。

世界模型预测：
  状态更复杂，但能覆盖更多业务 case。
  更符合唯一数据源和测试先行。
```

这就是“内在试错”：还没写代码，先让方案在脑内失败一次。

## 六、问题与澄清

| 问题 | AI 回答 | 是否已懂 |
|------|---------|----------|
| 世界模型是不是一个 LLM？ | 不一定。它可以由 LLM 扮演，也可以是规则、仿真器、测试用例、状态机推演或人写的预测清单。关键不在形式，而在是否能预测行动后果。 | ⬜ |
| 世界模型和工具反馈有什么区别？ | 世界模型是行动前预测；工具反馈是行动后事实。预测可以错，工具反馈才是外部真实观察。 | ⬜ |
| 世界模型和记忆有什么区别？ | 记忆提供过去的经验和上下文；世界模型用这些输入来推演未来可能发生什么。 | ⬜ |
| 世界模型为什么不能替代验证？ | 因为它只是模拟，不是真实执行。它能降低试错成本，但不能证明代码真的跑通。 | ⬜ |

| 它要从记忆里读取什么，才能预测得更准？ | 历史，需求，架构，边界，盲区，上一轮复盘 | ✅ 通过 | 已覆盖世界模型预测所需的主要记忆输入。 |

### 当前校正版

```text
世界模型会在行动前预测：
1. 安全/权限风险：会不会误删、越权、破坏无关代码。
2. 状态/流程风险：loading、refresh、loadMore 会不会互相覆盖。
3. 架构/质量风险：会不会破坏 clean arch、唯一数据源和测试覆盖。

它和工具反馈的区别：
  世界模型是行动前预测；工具反馈是行动后事实。

它要从记忆里读取：
  需求 case、历史失败、架构原则、边界约束、测试盲区、上一轮复盘。
```
