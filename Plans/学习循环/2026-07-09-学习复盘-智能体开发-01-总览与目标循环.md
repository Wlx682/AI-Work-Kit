## 十一、复盘

| 维度 | 内容 |
|------|------|
| 已掌握 | Agent 不是单次问答，也不只是工具调用；核心是围绕目标形成状态、反思、记忆驱动的循环。 |
| 已掌握 | System 2 负责规划、决策、反思、模拟；System 1 负责执行、工具调用、代码生成和快速响应。 |
| 已掌握 | 世界模型是行动前预测，不等于安全约束；工具反馈是行动后的事实校验；记忆是下一轮规划的输入约束。 |
| 已掌握 | memory 应整理成 context pack，提供给下一轮 LLM / Planner，而不是简单堆聊天历史。 |
| 未掌握 | 还没有真正写出可运行的最小 Agent 程序，后续需要用代码实践 state / reflection / memory。 |
| 误区 | 曾把“世界模型”理解成“约束 LLM 不跑偏”；已纠正为“行动前后果预测”。 |
| 最有价值的一点 | memory 不是仓库，而是下一轮规划的输入约束：需求 case + 公共原则 + 设计原则 → context pack → 框架设计。 |

### 本轮核心原则

```text
Agent = 目标 + 状态 + 规划/执行 + 观察反馈 + 反思 + 记忆
```

```text
memory -> context pack -> planner / LLM -> 下一轮行动
```
