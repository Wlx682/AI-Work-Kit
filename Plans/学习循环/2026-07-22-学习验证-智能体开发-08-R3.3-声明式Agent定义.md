# 学习验证：R3.3 声明式 Agent 定义

## 十、验证清单

| 验证项 | 方法 | 结果 |
|--------|------|------|
| 默认定义可加载 | 读取 JSON 与 Markdown | ✅ 测试通过 |
| 不存在工具被拒绝 | fixture 写入 `unknown_tool` | ✅ loader 抛出明确错误 |
| allowlist 生效 | 只声明 `read_file` | ✅ 执行层只向模型暴露 `read_file` schema |
| 安全边界 | 代码审查 `act._safe_run()` | ✅ allowlist 过滤后仍调用 `safety.check()` |
| 四角色定义 | 直接构造 Planner/Predictor/Executor/Reviewer | ✅ 每个 role 加载不同 definition ID |
| 角色到能力 | mock 共享能力调用 | ✅ 每个 role 都把自己的 definition 传入对应 capability |
| 回归检查 | 运行全部离线测试 | ✅ 11 项通过 |

### 概念验证

已回答：Planner 只做规划，和外部工具无关。`planning` 是共享 capability；`tools: []` 只禁止文件、Shell 等行动工具，不禁止调用无副作用的规划能力。

| 项 | 结论 |
|----|------|
