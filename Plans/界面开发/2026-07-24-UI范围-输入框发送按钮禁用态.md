# UI 范围确认：输入框发送按钮禁用态

**工作流**：`ui-change`  
**阶段**：`ui-scope` / UI 范围确认  
**推荐 Skill**：`figma-ui`  
**存放路径**：`Plans/界面开发/2026-07-24-UI范围-输入框发送按钮禁用态.md`

---

## 一、输入

- 来源：用户指定输入框发送按钮不可发送时，中间白色图标保持原透明度，仅调整背景；禁用背景色可直接使用 `red: 0.102, green: 0.102, blue: 0.102`。
- 平台：iOS / UIKit。
- 视觉基准：用户给出的精确颜色值；等价 8-bit 色值约为 `#1A1A1A`。
- Figma：未提供链接或节点，本次不进行 Figma 节点读取。

## 二、范围

- 调整标准输入框 `NMNewTextInputComponent` 的发送按钮禁用态。
- 覆盖发送按钮保持可见但不可发送的状态，包括展开输入框的不可发送态、附件上传中的不可发送态。
- 保持按钮交互禁用语义不变。

## 三、非目标

- 不修改发送可用性的业务判断。
- 不修改发送按钮尺寸、圆角、图标资源、布局和正常态颜色。
- 不调整旧版、深色版、语音版或弹出式输入组件。
- 不新增接口、埋点、状态机或数据处理。

## 四、验收标准

- [x] 禁用态按钮整体 `alpha = 1`。
- [x] 禁用态白色发送图标不被 UIKit 自动降透明度。
- [x] 禁用态背景为 `UIColor(red: 0.102, green: 0.102, blue: 0.102, alpha: 1)`。
- [x] 正常态仍为黑色背景，点击行为不变。
- [x] 其他 `NMInputButton` 默认禁用透明度行为保持不变。
