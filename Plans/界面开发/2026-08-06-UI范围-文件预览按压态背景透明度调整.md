# UI 范围确认：文件预览按压态背景透明度调整

**工作流**：`ui-change`
**阶段**：`ui-scope` / UI 范围确认
**推荐 Skill**：`figma-ui`
**存放路径**：`Plans/界面开发/2026-08-06-UI范围-文件预览按压态背景透明度调整.md`

---

## 一、输入

- 来源：用户截图与口头标注：文件预览底部按钮按压时，背景色不透明度为 80%，文字颜色不变。
- 范围：`NMFilePreviewBottomActionBar` 的按钮按压态颜色；四种外观/主次按钮组合统一遵循“原背景色 alpha 0.8”。
- 非目标：不调整默认态色值、文字色、字号、布局、圆角、图标、点击逻辑和文件预览业务流程。

## 二、阶段产出

- [x] 确认纯 UI 范围，无接口、埋点、状态机或跨模块业务逻辑。
- [x] 定位实现：`NAMIWork/Core/UI Components/FilePreview/NMFilePreviewManager.swift`。
- [x] 差异确认：深色主/次按钮与浅色主按钮已为原背景色 alpha 0.8；浅色次按钮仍为黑色 alpha 0.08，需要改为 `#F3F3F3` alpha 0.8。

## 三、视觉契约

| 状态 | 背景 | 文字 |
|---|---|---|
| 默认 | 保持现有背景色 | 保持现有文字色 |
| 按压 | 默认背景色，alpha = 0.8 | 与默认态相同 |
