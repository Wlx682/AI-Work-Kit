## 一、输入

- 来源：[Figma 输入框附件预览](https://www.figma.com/design/Z3hhNwFzvLZOdnCtXkIRHn/?node-id=23825-12121&m=dev)；固定 iOS `4d405cf0` 的 `NMMediaPreviewComponent` / `NMNewFileInputComponent` / `NMPhotoPickerViewController`。
- 平台：Flutter 共享 UI，iPhone 为本轮主验收形态，同一组件保持 Android/Pad/Fold 可用。
- 范围：还原输入框内图片/文件预览卡；最近照片上滑时按手指位移展开，松手进入自定义四列多选页，确认后走既有 owner/上限/上传链。
- 非目标：不修改上传协议、云盘/相机/系统相册按钮行为，不改输入框模型、ASR、算力豆及发送状态。

## 十、范围变更影响：全 App 对齐 iOS 动效

- 用户裁决：当前选择器动画过慢；全 App 离散 UI 动画统一采用 iOS 系统节奏。
- 原生证据：固定 iOS `4d405cf0` 中显式 UIKit 动画分布为 100/120/150/160/180/200/220/250/300ms；图片选择器虽然基准为 0.4s，但 `continueAnimation` 的 `durationFactor` 再乘原始时长，完整结束阶段实际最大约 160ms。
- 代码影响：设计系统 token、全局 Theme 页面转场、导航、输入框及现有显式 UI 动画组件；不修改轮询、重试、上传进度、网络超时和业务防抖。
- 实现结果：新增 `AppMotion`；全部宿主平台页面路由使用 `CupertinoPageTransitionsBuilder`；散落的离散 UI 时长已收敛到 token；选择器结束动画 400ms → 160ms；排行榜按压 80ms → 固定 iOS 对应的 200ms。
- 测试影响：设计系统/导航 110 条、输入框与排行榜 80 条、首页/项目/专家编辑 157 条、Claw 69 条、云盘/会员/项目编辑/设置 122 条均通过；静态分析 37 个改动 Dart 文件无问题。
- 未运行：完整 Android Phone/Pad/Fold 与 iPad 真机动效矩阵；当前 iPhone 已 Hot Restart 并到达 ready/首帧，等待人工触感验收。
