| 模块 | 修复落点 | 依赖边界 |
|---|---|---|
| Graph Authoring | `intelligence.py` 增加显式 revise 端口；`deepseek_intelligence.py` 删除质量依赖和静默 normalize | Adapter 只返回 schema-valid draft |
| Graph Quality/Governance | `service.py` 唯一编排最多两次 generate/revise，并统一 strict gate 与结构化 audit error | Application 决定审计与发布 |
| Persistence | `contracts.py` 增加原子 `_write` 与可恢复 repository transaction，create/apply/rollback 都在事务中执行 | 事务对上层只表现为 context manager |
| Observability | `debug_events.py` 增加 summary-only 默认、详细模式、clear、trace/span；`http_api.py` 贯穿请求 trace | 内容策略由 EventStore 统一执行 |
| Flutter | API 保留 error details；Banner 展示 finding；Debug 页增加隐私开关和清除 | UI 不推断后端质量规则 |
| Tests | 三组 Backend Red + 三组 Flutter Red，最后全量回归与 analyze | 先覆盖失败语义再实现 |
