# 修复落点设计：学习活动无效 JSON 未重试

## 修复落点设计

- Adapter 精确识别 `chat_json` 的“修复后仍无效 JSON”，映射为 `INVALID_INTELLIGENCE_OUTPUT`。
- `_call_validated` 将调用和 validator 放入同一个重试边界，最多重新生成一次。
- Timeout 测试保持 `LEARNING_INTELLIGENCE_FAILED` 且单次调用，防止扩大重试范围。
- 共享 JSON parser 只匹配包裹整个响应的外层 Markdown 围栏，字段内部代码块保持 JSON 内容。
- live 测试保留 Controller error 与后端 stdout/stderr，后续失败可直接定位。
- Evidence typed response 携带更新课程，Controller 在进入 Review 时立即刷新 progress/mastery。
