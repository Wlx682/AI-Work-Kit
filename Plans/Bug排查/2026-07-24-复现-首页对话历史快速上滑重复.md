## 一、输入

- 来源：用户报告“首页对话历史，从对话页返回时快速向上滑动，会出现数据重复”。
- 范围：首页 `.all` 会话历史列表返回刷新与上拉分页相邻触发的链路。
- 非目标：服务端分页协议改造、自动化 Tab `cron.list` 分页、列表 UI 样式。

## 二、阶段产出

- [x] 最小复现路径：历史列表至少两页 → 进入任一会话 → 返回首页 → 首屏静默刷新期间快速上滑触发下一页。
- [x] 复现条件对应代码链：`viewWillAppear` 静默刷新；在途时上拉挂起，刷新完成后补触发 `loadMore`。
- [x] 可观测结果：SWR 缓存帧已上屏但网络最终帧仍在途；此时上拉必须等待最终 cursor。最终帧刷新 UI 时 footer 异步回 idle，与 VM 同步重放分页之间存在错拍窗口。
- [x] 影响范围：共用 `NMTaskRecordListVM.loadMore()` 的分页列表均受时序策略影响，用户当前命中首页 `.all`。
