# 根因定位：文件预览 QL 边缘手势失效

**工作流**：`bugfix`

**推荐 Skill**：`feature-dev-assistant`

## 一、输入

- 来源：复现阶段确认 QL 文件预览页左缘右滑退出不可用。
- 范围：`NMFilePreviewController` QL 容器和 `NMFilePreviewManager.installEdgeDismissGesture` 注入的退出手势。
- 非目标：不调整文件类型分流、不改 QuickLook 数据源、不处理 WebView inspectable 既有改动。

## 二、阶段产出

- [x] QL 预览由 `NMFilePreviewController` 全屏模态展示，正文是 `QLPreviewController` 子控制器。
- [x] 文件预览统一左缘退出由 `NMPreviewEdgeDismissGestureRecognizer` 注入到外层 controller.view。
- [x] QuickLook 内部存在用于滚动/翻页/缩放的手势，触摸从内容区域开始时会与外层左缘退出手势竞争。
- [x] 根因：QuickLook 内容子视图先命中并参与滚动/翻页/缩放手势识别时，外层 controller.view 上的左缘退出手势可能收不到边缘起手触摸，表现为边缘手势失效。
