# 修复：真实 DeepSeek 五视图集成链路

## Findings-first

1. **模型无效 JSON 绕过重试**：App Adapter 把 `chat_json` 修复失败归类为 transport failure，结构化调用策略没有重新生成。
2. **共享 JSON parser 破坏字段内 Markdown**：响应任意位置出现 ``` 就被当作外层围栏，Tutor 代码示例导致合法 JSON 被截断。
3. **图谱节点数量契约漂移**：旧 live 测试限制 6–12、提示词固定 10，而已确认需求允许 6–40；15 节点的合法图谱被测试误判。
4. **Evidence 后课程状态未刷新**：后端已返回更新课程，Flutter typed client/Controller 丢弃该快照，进度页保留旧的 0。

## 修复

- 无效 JSON 映射为 `INVALID_INTELLIGENCE_OUTPUT`，validated call 最多完整重新生成一次；Timeout 等传输错误仍不重试。
- 共享 Agent parser 只剥离包裹整个响应的外层 ```json，保留 JSON 字符串内部 Markdown 代码块。
- 图谱生成与 live 验收统一为 6–40 节点，通常 10–20，按目标复杂度覆盖能力，不再强制固定数量。
- `RuntimeReview` 解析 Evidence 响应中的 `course`；Controller 立即刷新 course、selected node 和 recommendation cache。
- live 测试在 Goal/Practice 失败时输出 error code、details 和后端输出，不再用空指针遮蔽根因。
