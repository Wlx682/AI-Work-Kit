## 背景与目标

**需求**：纳米P视频 Web「视频生成」工作台——创作者把图/文/音/视频参考素材组合生成短视频的主入口。承接已交付的 [[纳米P视频web首页]]，同一技术栈与分层架构。
**技术栈**：React 19 + Vite 8 + TS 6 + Zustand 5 + @tanstack/react-query 5 + CSS Modules + Vitest 4 + MSW（沿用首页脚手架）。
**PRD**：https://my.feishu.cn/docx/JREidKSuuow04GxIBpKcsLbdndb
**Figma**：node-id 2-9561（参考生视频空态·主入口）· 2-6831 · 2-6895 · 2-6942 · 2-6997 · 2-7195 · 2-7283 · 2-7253 · 2-9009 · 2-8354 · 2-18213
（fileKey：o4XtLTcw56LUmy7YfjGE4g）

**核心指标**：新用户首次生成率 · 立即生成点击→提交转化 · 任务成功率 · 灵感中心承接「一键同款」率 · 会员/积分拦截转化。

**本期范围（仅参考生视频模式）**：
1. **顶栏** — 复用首页导航（当前页「视频生成」高亮）+ 资产库入口 + 积分胶囊（点击进积分消耗明细面板，会员态分支充值/升级）+ 头像下拉。
2. **左栏创作区** —
   - 素材上传区（空态虚线框；点击/拖拽；本地上传 + 从资产库选择；缩略图卡片 + `+` 追加；单张/多张 hover 预览浮层带切换箭头；素材聚合标签条）。
   - 提示词输入 + `@引用`（富文本扁平节点；@下拉/快捷按钮；**删除素材→同类型序号整体前移 + 提示词标签原子回写**；替换保留位次；粘贴降级；无素材点 @ 拦截 Toast）。
   - 参数胶囊（比例/时长/分辨率/数量，云控选项集合，切模型自动纠偏默认值）。
   - 模型选择胶囊（Seedance 2.0 / 2.0 Fast，云控下发，切模型联动重算素材有效性/参数/积分/按钮）。
   - 立即生成（预估消耗 + 串行判定链：登录态→会员SDK→提交or收银台；防抖 300ms；提交后草稿保留）。
3. **右栏任务结果区** — 顶部 Tab（任务列表 / 灵感中心承接）+ 任务三态（生成中占位/轮询、成功卡片+全屏播放、失败卡片+再次生成/重新编辑）+ 删除二次确认 + `superseded_by` 去重。
4. **拦截承接** — 登录/会员/积分拦截结束后自动恢复原提交动作。
5. **埋点** — key=`namivideo_video_gen`，attr=`video_gen_reference`（本期仅此模式），全量 §9.1 清单 + 服务端 §9.2。

**本期不做**：首尾帧模式（§3.5）、特效玩法（外链跳转占位）、灵感中心内容数据源（独立 PRD 承载，本期仅承接 Tab + 一键同款回填契约）、本地草稿持久化（刷新丢失）、并发任务上限。

**数据策略**：全 Mock 契约先行（MSW + `httpRepo` 按契约写好，`VITE_USE_MOCK` 切换）；模型云控、提交、任务轮询、积分预估、会员SDK 全部走 Mock 桩，待后端就绪联调（WBS 11）。
