## 背景与目标

**需求**：纳米P视频 Web 首页（homepage），面向电商运营 / 营销团队 / 短视频创作者的**流量入口与转化枢纽**。
**技术栈**：React 18 + TypeScript + Vite。
**PRD**：https://my.feishu.cn/docx/XmLrdC7v6oZQcBx78V9c5iKZn1d
**Figma**：node-id 2-4227（未登录）· 2-3920 · 2-4336 · 2-5114 · 2-5409
（fileKey：o4XtLTcw56LUmy7YfjGE4g）

**核心指标**：工具点击转化率 · 新用户首次生成率 · 灵感中心卡片点击率（含「一键同款」）· Banner 点击率。

**四大区块（自上而下）**：
1. **顶部导航栏** — Logo / 5 主导航（首页·视频生成·图片生成·灵感中心·创作工具）/ 资产库入口 / 积分胶囊 + 升级·充值胶囊（会员态分支）/ 头像下拉菜单；登录·未登录两态。
2. **Banner 横滑运营位** — 多图并列、手动切换、不自动轮播；箭头翻屏 + 分页指示器；云控 key `nano_pvideo_web_homebanner`。
3. **创意工具箱** — 云控 key `nano_pvideo_web_hometools`；「查看更多」入口。
4. **灵感中心** — 分类 Tab + 双内容形态（瀑布流 / 分组横滑）+ 内容卡片（悬停预览 + 一键同款）。

**附加**：骨架屏加载态 · 登录/未登录态 · 积分消耗明细面板 · 水印设置 Modal · 退出登录 Modal · 登录拦截 Modal · 完整埋点（key=namivideo_home）。

**本期不做**：站内搜索、个性化推荐、国际化/多语言。
