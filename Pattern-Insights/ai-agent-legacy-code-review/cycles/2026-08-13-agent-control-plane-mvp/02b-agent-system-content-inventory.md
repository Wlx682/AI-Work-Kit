# 智能体系统内容清单

> 先回答“系统里有什么”，暂不定义监控维度、指标或实现机制。这里的“内容”指系统运行时真实存在、流转、变化或产生影响的对象。

## 一、系统的目的与边界

1. **目的**：系统为什么存在，试图改变什么现实结果。
2. **任务意图**：本次工作具体想达成什么，不想达成什么。
3. **成功与失败定义**：什么结果算成功，什么结果即使流程完成也算失败。
4. **系统边界**：哪些人、Agent、工具、数据和外部系统属于本系统，哪些只是环境。
5. **影响对象**：系统最终影响的用户、业务、代码库、组织或现实资源。

## 二、参与者

6. **人**：发起者、领域专家、审批者、操作者、受影响者、责任承担者。
7. **Agent**：主 Agent、子 Agent、评估 Agent、守护 Agent，以及临时产生的 Agent 实例。
8. **模型**：每个 Agent 实际使用的基础模型、版本和推理配置。
9. **外部行动者**：其他团队、第三方服务、自动化系统和可能影响系统的攻击者。
10. **身份与关系**：谁代表谁行动、谁向谁委托、谁监督谁、谁对结果负责。

## 三、意图与约束

11. **目标**：用户目标、业务目标、局部任务目标和阶段目标。
12. **价值判断**：速度、质量、安全、成本之间如何取舍。
13. **规则**：政策、规范、流程要求、业务不变量和法律限制。
14. **权限**：谁可以读取、决定、执行、批准、发布和修改系统自身。
15. **承诺**：Agent 对用户、上游和下游作出的范围、质量、时间与结果承诺。

## 四、信息与认知材料

16. **输入**：用户请求、需求、事件、信号、文件和外部状态。
17. **上下文**：当前提供给 Agent、足以影响本轮判断的信息集合。
18. **知识**：文档、代码、数据库、领域知识、历史案例和外部检索结果。
19. **记忆**：短期会话记忆、长期记忆、个人偏好、组织经验和共享记忆。
20. **假设**：尚未验证但被系统用于继续行动的判断。
21. **不确定性**：信息缺失、歧义、冲突、未知和不可知部分。
22. **信息来源与谱系**：信息从哪里来、经过谁转换、当前是否仍有效。

## 五、能力

23. **模型能力**：理解、推理、生成、规划、反思和多模态处理能力。
24. **工具能力**：搜索、读写文件、执行代码、操作浏览器、调用 API、发送消息等。
25. **技能**：可复用的方法、工作流、领域操作规范和任务策略。
26. **环境能力**：沙箱、代码仓库、测试环境、网络、账号和基础设施提供的能力。
27. **人的能力**：领域判断、授权、纠偏、例外处理和责任承担。
28. **能力边界**：系统不会什么、不能做什么、当前条件下做不到什么。

## 六、工作对象与产物

29. **任务**：被委托的工作单元及其范围、依赖和生命周期。
30. **计划**：目标被分解后的阶段、步骤、顺序和资源安排。
31. **中间产物**：需求、方案、代码、测试、报告、数据、消息和审批材料。
32. **最终交付物**：系统向用户或外部环境正式交付的结果。
33. **证据**：支持某项事实、判断、变化或完成声明的可检查材料。
34. **问题与异常**：失败、冲突、偏差、阻塞、意外副作用和未决事项。

## 七、认知与决策过程

35. **理解**：系统如何解释目标、上下文和环境。
36. **判断**：系统认为哪些事实成立、哪些方案可行、风险在哪里。
37. **计划与选择**：候选行动如何产生、比较和取舍。
38. **决策**：哪个主体在什么依据下选择了什么行动。
39. **反思与修正**：系统如何发现前面理解或决策有误并改变方向。
40. **完成声明**：哪个主体基于什么理由认为工作已经完成。

## 八、协作与流转

41. **委托**：任务、权限、上下文和预期结果如何交给另一个参与者。
42. **通信**：人—Agent、Agent—Agent、Agent—工具之间交换的消息。
43. **交接**：中间产物、未决事项、上下文和责任如何转移。
44. **协调**：并行、串行、竞争、汇合、仲裁和依赖处理。
45. **反馈**：下游对上游产物的接受、拒绝、修改和补充。
46. **责任链**：每个决定、行动和结果最终可以追溯到谁。

## 九、行动与现实副作用

47. **行动提议**：Agent 想做什么以及为什么。
48. **实际行动**：系统最终真正执行了什么。
49. **作用对象**：行动影响的文件、分支、用户、账号、数据或外部系统。
50. **状态变化**：行动前后系统内部和外部世界发生了什么改变。
51. **副作用**：目标效果之外产生的连带影响。
52. **可逆性**：变化能否撤销、怎样撤销、撤销成本是什么。
53. **外部结果**：行动进入真实环境后产生的业务、用户和系统后果。

## 十、运行结构与运行状态

54. **控制流**：任务如何开始、路由、循环、暂停、恢复、结束。
55. **依赖关系**：任务、产物、状态和外部资源之间的前置关系。
56. **当前状态**：此刻进行到哪里、哪些事实成立、哪些工作未完成。
57. **历史轨迹**：系统此前经历过哪些状态、决策、行动和结果。
58. **并发状态**：多个 Agent 或任务同时运行时的共享状态和冲突。
59. **生命周期**：任务、Agent、产物、权限和记忆何时创建、更新、失效和销毁。
60. **版本**：模型、提示、技能、规则、工具、数据和工作流的具体版本。

## 十一、资源与运行条件

61. **时间**：截止时间、等待时间、延迟和信息的新鲜度。
62. **计算资源**：模型调用、token、CPU/GPU、存储和并发额度。
63. **经济资源**：调用成本、人力成本、机会成本和错误成本。
64. **注意力资源**：人类能够投入多少审查、判断和介入。
65. **环境条件**：网络、服务可用性、代码版本、数据状态和依赖系统状态。

## 十二、结果、评价与进化

66. **输出**：系统直接生成或执行的内容。
67. **结果**：输出进入环境后实际造成的变化。
68. **价值**：结果是否解决问题，给谁创造或损害了什么价值。
69. **评价**：谁用什么标准对过程、产物和结果作出判断。
70. **误判与漏判**：系统当时的评价与后来真实结果之间的差异。
71. **经验**：哪些事实被系统保留下来供未来使用。
72. **进化候选**：哪些模型、提示、技能、工具、规则、流程或组织关系被提议修改。
73. **系统变更**：最终批准并生效的能力或结构变化。
74. **进化后的新边界**：系统改变后新增的能力、风险、未知和责任。

## 最小抽象

如果压缩到最少，智能体系统包含六种基本内容：

1. **主体**：谁在参与和负责。
2. **意图**：系统要改变什么。
3. **认知材料**：系统依据什么理解和判断。
4. **行为**：系统怎样决定、协作和行动。
5. **世界状态**：系统内部与外部实际发生了什么变化。
6. **演化**：结果如何反过来改变系统自身。

监控维度不能从现成工具名推出，而应从这些内容在“产生、解释、转换、传递、执行、评价、演化”过程中可能发生的偏差中推导。
