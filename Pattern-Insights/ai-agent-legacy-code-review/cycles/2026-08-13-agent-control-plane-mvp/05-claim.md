# 核心主张

- **大多数人认为**：只要模型能力足够强，再补充规则、测试、权限和几个评估器，智能体就能自然升级为生产工具。
- **我观察到**：能力不等于生产力。Agent 会自主解释目标、选择路径并改变外部环境；能力越强、权限越大，错误也越可能从一次输出问题扩散为系统级副作用。人类如果不能持续认识和控制这个过程，得到的只是更强的能力演示或风险放大器。
- **核心主张**：生产自主权不是 Agent 的固有属性，而是控制系统根据每项能力的可观测、可干预、可安全降级和可校准程度，逐项授予的运行资格。
- **真正起作用的机制**：详尽监控在干预窗口内重建面向控制目标的动态系统镜像；控制器据此识别偏差，调用足以覆盖关键扰动的控制动作，并在 Agent 失灵时切换到独立、可验证的安全退路；真实结果再反向校准状态模型与控制律。
- **详尽监控的边界**：它是精细控制唯一可靠的认识基础，但不是完整控制解法。只有监控而没有不可绕过的行动通道，系统只能看见失控；只有控制动作而没有可靠状态镜像，系统只能盲目干预。
- **系统边界**：被控对象不是模型节点，而是“Agent—工具—环境—人—组织”组成的嵌套社会技术控制结构。Agent 是任务环境的下层控制器，人类控制面是上层监督控制器。
- **生产底线**：高风险能力如果没有不依赖 Agent 继续正确工作、独立且可验证的安全 fallback，不得自主进入生产；仍可在只读、沙箱或人工控制模式下运行。
- **行动与恢复边界**：具有外部副作用的行动必须同时接受事前精确授权与事后现实验证；恢复必须区分内部代码/运行状态回滚与外部世界的隔离、止损、对账和补偿。
- **只在什么条件下成立**：监控覆盖控制相关系统状态而非无差别收集全部数据；关键证据具有来源、时间、版本、不确定性和独立故障域；控制动作可在干预窗口内生效；安全收益持续高于误杀、时延、人工、基础设施和隐私成本。
- **对读者意味着**：技术负责人不应先问“哪个 Agent 最强”，而应先问“哪项能力已经具备可观测、可控和可安全降级的生产条件”。模型能力决定 Agent 能做什么，控制系统决定它被允许自主做什么。
- **最强证据**：Kalman 对可观测性与可控性的形式区分；Ashby 对控制器必要多样性的容量约束；Conant–Ashby 对调节器内部系统模型的要求；STAMP 对分层社会技术控制失效的解释；NASA Runtime Assurance 对监控器、切换器和独立安全通道的工程结构；Tax AI、CXI、Ledger 等 Agent 案例对执行状态、证据、精确授权和受控进化的局部验证。
- **最强反方观点**：这套控制面可能把高效自主工具变成昂贵、迟缓、过度保守的审批机器。关键状态可能不可观测，系统模型会过时，监控器与 fallback 也会失效；如果安全收益不能超过误杀、时延、人工和基础设施成本，它就不是生产工具，只是更复杂的阻塞系统。
- **验证方向**：用相同 Agent、模型、任务和故障集比较基线组、仅观测组与闭环控制组，同时报告静默失败、真实损失、干预时延、恢复净效果、误杀、任务时延、人工与基础设施成本。
