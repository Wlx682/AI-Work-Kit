## 事实与引用核验

- **AgentSpec：已核验。** arXiv v3 显示论文于 2025-03-24 首次提交、2025-07-31 修订，并被 ICSE 2026 接收。论文确实使用 `trigger—check/predicate—enforce` 结构，在离散执行检查点对预定义约束进行外部运行时强制；作者也明确说明它不分析当前动作的长期轨迹后果。来源：[AgentSpec](https://arxiv.org/abs/2503.18666)。
- **Real-Time Detection and Repair：已核验。** 论文于 2026-08-03 提交，覆盖 2,823 条 Agent 运行轨迹；它报告逐步遥测、完成度检查、确定性验证和回滚修复，并明确指出监控需要按部署校准、合理数值错误需要外部参照。来源：[Real-Time Detection and Repair of LLM Agent Failures](https://arxiv.org/abs/2608.02464)。
- **推断边界：已标记。** “错误迁移到智能体系统层”“四种不确定性治理性质”“三类协同能力”“进化本身也必须可断言”是用户判断与本文架构推导，不是上述论文的直接结论。
- **引用方式：通过。** 正文均使用转述，没有长段逐字引用。
