# 核心主张

- 大多数人认为：要让 AI Agent 可靠，首先要把需求和规则定义得更明确，再增加更多检查。
- 我观察到：需求意图只能在测试和迭代中逐步涌现；强大的 LLM 已经可以通过既有代码断言，却仍可能让任务顺利完成并产生整体错误，而且系统没有及时反馈。
- 真正起作用的机制（用户已确认，2026-08-12）：不是把 LLM 约束成确定程序，而是建立一套围绕其不确定性运行的可进化工作流架构，使不确定性可观测、后果有边界、失败可恢复、经验可进化。
- 只在什么条件下成立：目标会在迭代中涌现、存在跨环节传递、多级代理指标和高频 Agent 执行，且局部成功可能掩盖整体错误的复杂工作流。
- 对读者意味着：技术负责人首先要设计的不是静态规则清单，而是能够持续承载生成、证据、控制和进化的系统闭环。
